# About Me & Global Dev Blog

Welcome to **Global Dev Blog**, an independent engineering lab notebook and technical troubleshooting publication authored by **Jihwan Park (`jbjihwan`)**.

This blog documents hands-on debugging postmortems, raw error tracebacks, failed hypotheses, and verified code fixes across **Python Systems, Deep Computer Vision, Autonomous Robotics, Aerospace Mission Replanning, and Web Supply Chain Security**.

---

## 👨‍💻 Who I Am

I am an AI and Robotics Software Engineer focused on turning mathematical algorithms into reliable edge and backend systems—and documenting the exact bugs encountered along the way:

- **Aerospace & Real-Time Mission Replanning**: Tactical data link (Link 16) packet serialization, RFC 8785 deterministic JSON canonicalization, Ed25519 multi-signature verification, and CPython A* graph search latency optimization (`31.4s -> 0.25s`).
- **Deep Computer Vision & Real-Time ITS**: 30 FPS highway dashcam pipelines, hierarchical YOLOv3/v5 license plate localization, CSRT correlation tracking, EDSR_x4 deep super-resolution, and temporal majority voting OCR.
- **Autonomous Robotics & Reinforcement Learning**: Tabular Q-Learning over 648 discretized sensor states, dense velocity/distance reward shaping, and physical Sim-to-Real transfer from Webots to dual-motor Arduino hardware.
- **LLM Fine-Tuning & Full-Stack Backend Debugging**: Llama 3.1 chat template tokenization fixes, resilient HTTP 429 rate-limit state machines, and FastAPI + PostgreSQL authentication debugging.
- **Systems & Supply Chain Security**: Windows `socket.getaddrinfo` DNS timeout isolation, UTF-16 null-byte HTML normalization, `npm overrides` transitive CVE patching, and static site threat modeling.

## 🛡️ Editorial Policy & Verification Standards

1. **100% Empirically Tested & Reproducible**:  
   Every error log, Python/TypeScript patch, and benchmark figure published on this blog is captured from actual runs on our lab workstation (NVIDIA GeForce RTX 4060 GPU, AMD Ryzen 7, 32GB RAM, Windows 11 / Ubuntu WSL2, Python 3.12, Node.js 20+).
