# 배포 대기 포스팅 보관함 (Staging Repository)

> **용도**: 앞으로 작성하는 모든 신규 블로그 포스팅 및 번역 원고는 사용자의 명시적인 배포 명령(`"배포해"`, `"배포 진행해"`)이 있기 전까지 이곳에 안전하게 보관됩니다.  
> **배포 정책**: Docusaurus의 `blog/` 및 `i18n/` 운영 디렉터리에 직접 작성하지 않으므로, 정기 빌드나 다른 작업 시 임의로 라이브 배포되지 않습니다.

---

## 📂 폴더 구조 규격

각 포스팅은 독립된 서브 디렉터리로 관리되며 아래 표준 규격을 준수합니다:

```text
배포대기/
├── [YYYY-MM-DD-slug-name]/
│   ├── blog/
│   │   ├── index.md             # 영문(EN) 기본 원고 (SEO 메타데이터 포함)
│   │   └── images/              # 고해상도 아키텍처 다이어그램 및 시각화 이미지
│   ├── i18n/
│   │   ├── ko/index.md          # 한국어(KO) 원고 + 3~5줄 핵심 요약
│   │   ├── ja/index.md          # 일본어(JA) 원고 + 3~5줄 핵심 요약
│   │   ├── es/index.md          # 스페인어(ES) 원고 + 3~5줄 핵심 요약
│   │   ├── zh-Hans/index.md     # 중국어 간체(ZH-Hans) 원고 + 3~5줄 핵심 요약
│   │   └── zh-Hant/index.md     # 중국어 번체(ZH-Hant) 원고 + 3~5줄 핵심 요약
│   ├── naver/
│   │   ├── post.md              # 네이버 블로그 스마트에디터 최적화 원고
│   │   └── meta.json            # 추천 제목 3안, 태그 10개, SEO 키워드
│   └── stage_info.json          # 포스팅 메타데이터 (시리즈, 회차, 승인 대기 상태)
└── naver_conversions/           # 기존 글로벌 블로그 글의 네이버 블로그 전용 변환 원고함
```

## 🚀 배포 절차 (사용자 승인 시)

사용자가 배포를 지시하면 `tools/deploy_staged_post.py` 유틸리티를 통해:
1. 해당 폴더의 파일들을 `blog/` 및 `i18n/` 운영 경로로 복사
2. `publish.ps1`을 실행하여 6개 국어 Docusaurus 정적 빌드 및 GitHub Pages/Cloudflare 라이브 배포
3. 배포 완료 후 `배포대기` 목록에서 `배포완료/`로 상태 변경
