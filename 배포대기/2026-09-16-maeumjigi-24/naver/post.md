## 1. 머신러닝의 흔한 결측치 대체, 정신의학에선 치명적인 이유

캐글이나 정형 데이터 경진대회에서는 빈 값이 있으면 흔히 전체 평균값(`mean`)으로 채우거나, 직전 관측값을 끝까지 끌어다 쓰는 Forward Fill(`ffill()`)을 사용합니다.

하지만 자살 위기 감지 파이프라인에서 이런 방식을 그대로 썼다가는 끔찍한 오작동이 일어납니다:

1. **무제한 Forward Fill의 비극 (오경보 폭발)**:
   - 환자가 3달 전 우울 척도(PHQ-9)에서 최고 위험 점수인 24점을 기록했습니다.
   - 이후 90일 동안 환자가 앱에 접속하지 않았는데, 이전 점수(24점)를 90일 내내 계속 유지해 버리면 어떻게 될까요?
   - 최근 상태에 대한 아무런 근거가 없는데도 85일 차에 응급 위기 경보를 울려버리는 심각한 오경보(False Positive)가 발생합니다.
2. **평균값 대체(Mean Imputation)의 치명적 함정 (위기 간과)**:
   - 더 무서운 것은 평균값 대체입니다. 환자가 극심한 우울증으로 침대에서 손가락 하나 까딱할 수 없어 설문을 전혀 하지 못했습니다.
   - 이때 결측치를 전체 이용자 평균(예: 8점 - 경미한 수준)으로 채워버리면, **실제로는 자살 위기에 처한 환자를 "안전하다"고 오판하여 방치하는 치명적인 위기 간과(False Negative)**가 발생합니다.

## 2. 결측 자체가 중요한 증상이다: 정보성 결측 (MNAR)

통계학에서는 결측치를 세 가지로 분류합니다:
- **MCAR (완전 무작위 결측)**: 네트워크 오류 등으로 데이터가 무작위로 유실된 경우
- **MAR (무작위 결측)**: 다른 관측 변수와 관련이 있지만 결측 자체는 조건부 독립인 경우
- **MNAR (비무작위/정보성 결측, Missing Not at Random)**: **결측된 이유 자체가 그 변수의 상태와 직접 연관되어 있는 경우!**

정신건강 분야에서 환자가 설문을 건너뛰는 것은 네트워크 오류(MCAR)가 아닙니다. **행동적 회피(Avoidance), 극심한 정신운동 지체, 무감동증** 등 우울증이 극도로 악화되었음을 보여주는 **명백한 임상적 증상(MNAR)**입니다.

따라서 AI 모델에게 *"이 환자는 설문 점수가 없으니 적당히 평균으로 넘어가자"*고 하면 안 됩니다. **"설문을 하지 않았다(결측)는 사실 자체를 위험 예측의 중요한 피처(Feature)"**로 학습시켜야 합니다!

## 3. 4대 임상 척도의 독립성: 하나로 뭉개면 안 되는 이유

마음지기 시스템은 4가지 임상 심리 척도를 주기적으로 수집합니다:

1. **PHQ-9 (우울증 선별도구)**: 0~27점 (주요 우울 장애 MDD 평가)
2. **GAD-7 (범불안장애 척도)**: 0~21점 (공황 발작 및 급성 불안 평가)
3. **PSS (지각된 스트레스)**: 0~40점 (만성적 사회심리 스트레스)
4. **ISI (불면증 심각도)**: 0~28점 (수면 리듬 및 수면 장애)

처음에는 이 4개 점수를 더해서 0~1 사이의 단일 종합 점수로 합치려는 아이디어도 있었습니다. 하지만 지도교수님 자문 결과 이는 절대 해서는 안 될 설계였습니다.

**급성 공황 상태로 심장이 터질 것 같은 환자(불안 21점, 우울 2점)**와, **공황은 전혀 없지만 극심한 무기력에 빠진 만성 우울 환자(불안 0점, 우울 23점)**가 단일 점수로는 똑같이 계산되어 버리기 때문입니다. 두 환자의 임상적 치료와 위기 개입 프로토콜은 완전히 정반대입니다. 따라서 저희는 **4개의 독립된 채널을 100% 보존**하는 설계를 채택했습니다.

## 4. 14일 LOCF + 결측 지표(Indicator) 구현 코드

저희 팀이 구현한 핵심 전처리 로직은 다음과 같습니다:

```python
# 14일 Bounded LOCF + MNAR 결측 플래그 파이프라인
import pandas as pd
import numpy as np

SCALE_BOUNDS = {
    "phq9": (0, 27),
    "gad7": (0, 21),
    "pss": (0, 40),
    "isi": (0, 28)
}

def process_patient_timeline(df: pd.DataFrame, max_locf_days: int = 14) -> pd.DataFrame:
    df = df.sort_values("timestamp").copy()
    processed_cols = {}

    for scale, (min_val, max_val) in SCALE_BOUNDS.items():
        val_col = f"{scale}_score"
        
        # 1. 원점(0)을 보존하는 Min-Max 정규화 [0, 1]
        norm_series = (df[val_col] - min_val) / (max_val - min_val)
        
        # 2. 최근 14일까지만 직전 관측값을 인정 (Bounded LOCF)
        locf_series = norm_series.ffill(limit=max_locf_days)
        
        # 3. 결측 지표 플래그: 데이터가 없거나 14일이 지나 만료되었으면 1.0, 정상이면 0.0
        missing_indicator = locf_series.isna().astype(np.float32)
        
        # 4. 잔여 결측치는 안전하게 0.0으로 대체 (지표가 1.0이므로 모델이 결측 상태임을 인식)
        final_scores = locf_series.fillna(0.0)
        
        processed_cols[f"{scale}_norm"] = final_scores
        processed_cols[f"{scale}_missing"] = missing_indicator

    return pd.DataFrame(processed_cols, index=df.index)
```

이 코드를 통과하면:
- 설문 제출 후 14일 동안은 유효한 임상 점수가 유지되며 `missing_indicator = 0.0`입니다.
- 14일이 넘어가면 점수는 만료되고 `missing_indicator = 1.0`으로 자동 전환되어, 신경망 모델이 장기 무응답 행동 패턴을 스스로 학습하게 됩니다.

## 5. 텍스트 대화 LLM과의 멀티모달 결합

이렇게 전처리된 14일간의 수치 벡터는 Qwen 2.5 파인튜닝 모델의 텍스트 히든 스테이트(Hidden States)와 **교차 주의집중(Cross-Attention) 게이트**를 통해 하나로 융합됩니다.

- 환자가 겉으로는 *"오늘 날씨 좋네요"*라며 덤덤하게 말하더라도, 지난 14일간의 우울/불면 점수가 급상승했거나 결측 지표가 켜져 있다면 AI가 즉각 고위험 징후를 포착합니다.
- 반대로 환자가 *"오늘 과제 때문에 죽겠다"*며 일상적인 과장 표현을 쓰더라도, 객관적인 심리 척도가 안정권이라면 불필요한 위기 경보를 울리지 않습니다.

## 📌 핵심 4줄 요약
1. **임상 데이터의 특수성**: 일반 머신러닝의 평균 대체나 무한 Forward-fill은 정신건강 위기 감지에서 치명적인 오경보와 위기 간과를 유발합니다.
2. **정보성 결측 (MNAR)**: 우울증 환자의 설문 미응답은 단순 노이즈가 아니라 행동적 회피와 상태 악화를 나타내는 중요한 임상 신호입니다.
3. **14일 LOCF + 결측 플래그**: 최근 14일까지만 관측값을 인정하고, 만료 시 결측 지표를 1.0으로 세팅하여 모델이 무응답 행동을 직접 학습하도록 설계했습니다.
4. **멀티모달 시너지**: 텍스트 대화와 14일 임상 수치 추세를 결합하여 오경보와 누락을 동시에 잡는 신뢰도 높은 위기 감지 시스템을 구축 중입니다.
