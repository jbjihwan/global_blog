안녕하세요! 로봇 공학과 인공지능을 결합한 실전 강화학습 프로젝트를 소개해 드립니다.

자율주행 모바일 로봇이 미지의 실내 공간에서 장애물을 요리조리 피하며 목표 지점까지 스스로 찾아가게 만드는 것은 로보틱스 엔지니어들의 오랜 로망입니다.

요즘은 DQN이나 PPO 같은 심층 신경망 기반 강화학습(Deep RL)이 대세이지만, 라즈베리파이나 임베디드 보드처럼 자원이 극도로 제한된 환경에서는 연산량이 너무 무겁고, 신경망 가중치 내부를 직관적으로 해석하기 어렵다는 단점이 있습니다.

그래서 이번 시리즈에서는 **가장 직관적이면서도 수학적 수렴성이 증명된 '표 기반 강화학습(Tabular Q-Learning)'**을 활용하여, 3D 로봇 물리 시뮬레이터인 **Webots** 환경에서 100% 자율주행 로봇을 구현해 보았습니다.

이번 1편에서는 연속적인 거리 센서 값을 어떻게 **648개의 이산 상태(Discretized State)**로 압축했는지, 그리고 Webots 시뮬레이터와 파이썬 강화학습 엔진을 **TCP 소켓 통신**으로 어떻게 엮었는지 그 아키텍처를 소개합니다!

## 1. 연속 센서값의 저주: 상태 공간 폭발 문제

로봇에는 초음파 센서나 적외선 센서가 달려 있어 장애물과의 거리를 `0.12m`, `0.45m` 같은 실수(Float) 단위의 연속값으로 읽어옵니다.

만약 이 연속값을 그대로 테이블 기반 Q-Learning의 행(State)으로 쓰려고 하면 상태의 수가 무한대로 폭발(State Space Explosion)하여 표(Q-Table)를 만들 수가 없습니다!

그렇다고 센서 값을 너무 거칠게 줄여버리면 로봇이 장애물의 위치를 분간하지 못해 벽에 들이박게 됩니다.

저희가 고안한 해결책은 **물리적 의미를 살린 기하학적 구간 분할(Discretization)**입니다:

- **목표물 방향 각도**: 좌/중/우 (3개 구간)
- **목표물 거리**: 근거리/중거리/원거리 (8개 구간)
- **전방 장애물 거리**: 위험/경고/안전 (3개 구간)
- **좌측 장애물 거리**: 위험/경고/안전 (3개 구간)
- **우측 장애물 거리**: 위험/경고/안전 (3개 구간)

이 5가지 조건을 곱하면:
``전체 상태 수 = 3 \times 8 \times 3 \times 3 \times 3 = 648개``

단 **648개의 정수(0 ~ 647)**만으로 로봇이 처한 모든 물리적 상황을 완벽하게 표현할 수 있게 된 것입니다!

## 2. Webots와 파이썬을 잇는 TCP 소켓 IPC 아키텍처

Webots 시뮬레이터의 물리 엔진은 32ms 주기로 째깍째깍 돌아갑니다. 파이썬 강화학습 에이전트가 로봇과 부드럽게 통신하려면 빠르고 가벼운 IPC(프로세스 간 통신)가 필수적입니다.

저희는 로컬 포트 5000번을 열고 **줄바꿈 구분자 기반의 경량 JSON(Line-delimited JSON)** 통신 파이프라인을 구축했습니다:

1. **파이썬 에이전트 -> Webots**: 행동 명령 전송
   `{"type": "step", "action": 0}` (0: 전진, 1: 후진, 2: 좌회전, 3: 우회전)
2. **Webots 시뮬레이터**: 480ms 동안 모터 구동 및 센서 측정
3. **Webots -> 파이썬 에이전트**: 측정된 센서값과 보상 반환
   `{"state": [0.45, 0.12, 0.35, 0.28, 0.40], "reward": 0.05, "done": false}`

이 구조 덕분에 파이썬 에이전트는 OpenAI Gym 스타일의 `env.step(action)` 인터페이스를 완벽하게 유지하면서 초당 수십 회의 초고속 학습 루프를 돌릴 수 있었습니다.

## 3. 핵심 이산화(Discretizer) 구현 코드

연속 센서값을 0~647 사이의 고유 인덱스로 변환하는 핵심 로직입니다:

```python
# discretizer.py - 5차원 연속 센서를 648개 정수 상태로 변환
import numpy as np

class Discretizer:
    def __init__(self):
        # 센서별 임계값 경계 정의
        self.front_bins = [0.15, 0.35] # 위험, 경고, 안전
        self.left_bins = [0.12, 0.30]
        self.right_bins = [0.12, 0.30]
        self.target_dist_bins = np.linspace(0.1, 1.5, 7) # 8개 구간
        self.target_angle_bins = [-0.35, 0.35] # 좌, 중, 우 3구간

    def get_state_index(self, obs: dict) -> int:
        # 각 센서값의 구간(bin) 결정 (0, 1, 2...)
        f_idx = np.digitize(obs['front_dist'], self.front_bins)
        l_idx = np.digitize(obs['left_dist'], self.left_bins)
        r_idx = np.digitize(obs['right_dist'], self.right_bins)
        d_idx = np.digitize(obs['target_dist'], self.target_dist_bins)
        a_idx = np.digitize(obs['target_angle'], self.target_angle_bins)

        # 5차원 좌표를 1차원 고유 정수(0~647)로 팩킹
        state = a_idx * (8 * 3 * 3 * 3) + \
                d_idx * (3 * 3 * 3) + \
                f_idx * (3 * 3) + \
                l_idx * 3 + \
                r_idx
        return int(state)
```

`O(1)`의 연산량으로 상태를 즉시 찾아내기 때문에 Q-Table을 읽고 쓸 때 지연 시간이 0.001ms 미만으로 극도로 빠릅니다.
