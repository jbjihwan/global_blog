# [Webots 로보틱스 #5] 가상 시뮬레이터에서 배운 AI, 진짜 현실 아두이노 로봇에 넣었더니?! (Sim-to-Real 완결편)

안녕하세요! 파이썬과 Webots 시뮬레이터로 구현하는 초경량 표 기반 강화학습(Tabular Q-Learning) 자율주행 시리즈 마지막 5편입니다.

지난 1~4편에 걸쳐 3D 시뮬레이터 속 로봇을 93% 이상의 완벽한 자율주행체로 훈련시켰습니다.

하지만 모든 로봇 공학자들이 말하길, **"시뮬레이터에서 잘 되는 건 아무것도 아니다. 진짜 현실 세계(Real World)에 올려봐야 안다!"**라고 합니다.

가상 세계에서는 바퀴가 미끄러지지도 않고, 모터 속도도 완벽하며, 센서 노이즈도 없습니다. 하지만 현실의 하드웨어는 바닥 마찰, 배터리 방전, 저가형 센서 튐 등 온갖 가혹한 복병이 도사리고 있습니다. 이를 바로 **'Sim-to-Real 간극(Reality Gap)'**이라고 부릅니다.

게다가 저희 로봇의 두뇌는 고작 2KB RAM을 가진 초소형 마이크로컨트롤러 **아두이노 우노(Arduino Uno)**였습니다!

이번 완결편에서는 가상에서 학습된 Q-Table을 실제 2륜 아두이노 로봇에 이식하고, **천장 웹캠과 ArUco 마커 비전 추적**을 결합하여 현실 세계 자율주행에 성공한 최종 프로젝트 과정을 공개합니다!

---

## 1. Sim-to-Real의 장벽과 분산 제어 아키텍처

아두이노 우노의 메모리(SRAM 2KB)로는 파이썬 코드나 Q-Table 배열을 통째로 올릴 수 없습니다. 

그래서 저희는 **"두뇌는 PC에서, 근육은 아두이노에서"**라는 분산 제어 시스템을 구축했습니다:

1. **천장 웹캠 + ArUco 마커 (Global Vision)**:
   - 로봇 정수리와 아레나 4개 모서리에 ArUco 마커를 붙이고, 천장 웹캠으로 로봇의 2D 평면 좌표 $(x, y)$와 바라보는 각도 $\theta$를 30fps로 오차 없이 실시간 추적합니다.
2. **호스트 PC 파이썬 엔진 (Brain)**:
   - 추적된 위치와 장애물 거리를 648개 상태로 변환한 뒤, 학습된 Q-Table에서 최적의 액션(0~3)을 0.002ms 만에 결정합니다.
3. **HC-06 블루투스 통신 (Nerve)**:
   - 115,200 baud의 초고속 블루투스 무선 시리얼로 아두이노에게 단 1바이트 명령(0: 전진, 1: 후진, 2: 좌회전, 3: 우회전)을 쏩니다.
4. **아두이노 우노 펌웨어 (Muscle)**:
   - 날아온 명령 바이트를 받아 L298N 모터 드라이버의 PWM 핀을 제어하여 바퀴를 굴립니다.

## 2. 천장 비전 호모그래피(Homography) 보정

웹캠 렌즈에는 필연적으로 왜곡(Fisheye Distortion)이 생깁니다. 아레나의 네 모서리 마커를 인식하여 비스듬한 카메라 시점을 완벽한 직교 평면으로 펴주는 **투시 변환(Perspective Transform)**을 적용했습니다:

```python
# vision.py - ArUco 마커 기반 실시간 호모그래피 위치 추적
import cv2
import numpy as np

# 아레나 4개 코너 마커로부터 1.2m x 1.2m 정사각 평면 투시 행렬(H) 계산
H, _ = cv2.findHomography(src_corners, dst_arena_pts)

def get_robot_pose(frame):
    # ArUco 마커 검출 (ID: 0)
    corners, ids, _ = cv2.aruco.detectMarkers(frame, aruco_dict)
    if ids is not None and 0 in ids:
        center = corners[0].mean(axis=1)[0]
        # 원근 왜곡을 제거한 실제 아레나 평면 좌표로 변환
        world_pt = cv2.perspectiveTransform(np.array([[center]]), H)
        heading = calculate_heading(corners[0][0])
        return world_pt[0][0], heading # (x, y, theta)
    return None
```

## 3. 현실 세계 최종 주행 테스트 결과

Webots 가상 시뮬레이터에서 훈련받은 지능 그대로, 한 번의 추가 현실 재학습 없이 실제 아레나에 로봇을 투입했습니다:

- **실제 하드웨어 목표 도달 성공률**: **86.7%** (30회 시험 중 26회 무충돌 골인!)
- **충돌 원인 분석**: 배터리 전압이 7.4V 이하로 떨어지며 모터 토크가 순간적으로 줄어들었을 때 발생한 오차였습니다.
- **결론**: 시뮬레이터에서 수학적으로 잘 정제된 상태 공간(648-bin)과 보상 셰이핑을 거친 Q-Table은, 현실 세계의 복잡한 물리 노이즈 속에서도 흔들림 없이 목표를 찾아가는 놀라운 전이(Transfer) 능력을 보여주었습니다!

## 📌 5부작 시리즈 최종 요약
1. **1편**: 연속 센서 데이터를 648개 정수로 기하학적 이산화하고 Webots TCP 소켓 IPC 통신 구축.
2. **2편**: 벨만 최적 방정식과 포텐셜 거리 보상 셰이핑으로 제자리 회전 로봇을 직진 주행체로 진화.
3. **3편**: 12개 벽 장애물 맵에서 3방향 헤드스캔과 할인율($\gamma=0.99$)로 지역 최적해(Local Minima) 극복 및 Headless 10배 가속.
4. **4편**: 탐색률 0% 결정론적 평가에서 93.3% 성공률로 딥러닝 DQN 대비 가볍고 빠른 실용적 우수성 입증.
5. **5편**: ArUco 마커 천장 비전 추적과 블루투스 분산 제어로 가상 Q-Table을 아두이노 현실 로봇에 이식(Sim-to-Real 86.7% 달성).
