# [AI 블랙박스 #1] 뭉개진 번호판도 선명하게 잡아낸다! 차선 침범 적발 & 초해상화 6단계 비전 시스템 설계

안녕하세요! 컴퓨터 비전과 딥러닝을 결합하여 실전 문제를 해결하는 비전 AI 엔지니어링 블로그입니다.

고속도로나 시내 도로를 운전하다 보면 아찔하게 차선을 밟고 넘어오는 차선 침범(칼치기) 차량들을 종종 마주치게 됩니다.

교통사고 예방과 무인 법규 단속을 위해 차량용 블랙박스 영상을 자동으로 분석하는 AI 시스템에 대한 수요가 급증하고 있지만, 실제 블랙박스 영상을 인공지능 모델에 넣어보면 처참한 문제들에 부딪히게 됩니다:

1. **지옥의 저화질**: 후방이나 옆 차선의 번호판 영역은 640x480 전체 화면에서 고작 **가로 40픽셀, 세로 20픽셀**에 불과합니다. 한글 음절('가', '나', '다')과 숫자의 획이 한 덩어리로 뭉개져 일반 OCR로는 절대 읽을 수 없습니다.
2. **노면 진동과 흔들림**: 차가 덜컹거릴 때마다 차선이 휘어지고 왜곡됩니다.
3. **연산량 폭발**: 무거운 비전 트랜스포머를 매 프레임 전체 화면에 돌리면 프레임이 5 FPS로 곤두박질치며 실시간 분석이 불가능합니다.

이번 시리즈에서는 이러한 한계를 극복하고, 저사양 엣지 환경에서도 **30 FPS 이상의 실시간 속도**를 유지하면서 **EDSR 딥러닝 4배 초해상화(Super-Resolution)**와 **시간 축 다수결 투표(Majority Voting)**로 뭉개진 번호판을 완벽하게 읽어내는 **6단계 비전 AI 파이프라인**을 상세히 소개합니다!

---

## 1. 6단계 계층형 파이프라인 아키텍처

불필요한 GPU 낭비를 없애기 위해 전체 프레임에서 거대한 신경망을 돌리지 않고, 필요한 순간에만 국소적으로 신경망을 깨우는 **계층형(Hierarchical) 파이프라인**을 설계했습니다:

```
[ 1단계: 동적 차선 추출 ] ──┐
  (Canny + Hough 변환)     │
                           ├─> [ 3단계: 침범 판정 ] ──(침범 시)──> [ 4단계: 번호판 탐지 ]
[ 2단계: 주변 차량 검출 ] ──┘     (차량 바닥 접지면 IoU)            (차량 내부 YOLOv5)
  (경량 YOLOv3-tiny)                                                        │
                                                                            ▼
[ 최종 번호판 확정: 64가1511 ] <── [ 6단계: OCR 다수결 ] <── [ 5단계: EDSR 초해상화 ]
                                   (EasyOCR + 정규식 큐)        (딥러닝 4배 선명화 복원)
```

1. **1단계 (차선 검출)**: 소실점을 고려한 사다리꼴 ROI 마스킹과 Canny/Hough 변환으로 내 차로의 좌/우 경계선을 동적으로 추적합니다.
2. **2단계 (차량 검출)**: 가벼운 YOLOv3-tiny 모델로 주변 차량의 바운딩 박스를 밀리초 단위로 찾아냅니다.
3. **3단계 (침범 판정)**: 차량의 밑바닥 바퀴 접지면(Footprint)과 차선 다각형 간의 겹침 비율(IoU)이 0.05를 넘으면 '차선 침범 위반'으로 즉각 판정합니다.
4. **4단계 (번호판 국소 탐지)**: 침범이 확인된 차량의 영역(ROI) 안에서만 번호판 전용 YOLOv5를 실행하여 불필요한 전체 화면 연산을 제거합니다.
5. **5단계 (EDSR 초해상화)**: 30x15 픽셀로 뭉개진 번호판 패치를 딥러닝 EDSR_x4 모델에 넣어 획과 엣지를 4배 고해상도로 선명하게 복원합니다.
6. **6단계 (OCR 다수결 앙상블)**: EasyOCR로 글자를 읽은 뒤, 대한민국 자동차 번호판 정규식(`^\d{2,3}[가-힣]\d{4}$`) 필터와 최근 7프레임 다수결 투표(Majority Voting)를 거쳐 오인식률을 0%에 수렴시킵니다.

## 2. 핵심 시스템 파라미터 설계 (`CONFIG`)

실시간성과 판독 정밀도의 황금 밸런스를 맞추기 위해 설정한 핵심 설정값입니다:

```python
# config.py - 실시간 ANPR 파이프라인 설정
CONFIG = {
    # 1. 차선 침범 판정 임계치
    "LANE_INT_THRESH": 0.05,       # 바닥면과 차선 겹침 비율 5% 초과 시 침범
    
    # 2. YOLO 탐지 신뢰도
    "VEHICLE_CONF": 0.40,          # 차량 검출 신뢰도 40%
    "PLATE_CONF": 0.35,            # 번호판 국소 탐지 신뢰도 35%
    
    # 3. EDSR 딥러닝 초해상화
    "SR_MODEL": "EDSR_x4.pb",      # 4배 확대 심층 잔차 신경망
    "TARGET_PLATE_W": 200,         # OCR 최적 가로 해상도 (200px)
    
    # 4. 시간 축 다수결 투표 앙상블
    "HISTORY_WINDOW": 7,           # 최근 7프레임 인식 결과 보관
    "VOTE_MIN_COUNT": 3            # 최소 3프레임 이상 일치 시 최종 확정
}
```
