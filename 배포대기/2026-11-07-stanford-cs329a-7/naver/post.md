# [스탠포드 CS329A #7] 개방형 진화: 코드가 유전자가 되어 에이전트 스스로를 진화시키는 신세계

안녕하세요! **Stanford CS329A: Self-Improving AI Agents (스스로 발전하는 AI 에이전트)** 제7강 해설입니다.

인공지능의 역사를 되돌아보면 언제나 반복되는 거대한 법칙이 하나 있습니다. 
컴퓨팅의 선구자 리처드 서튼(Richard Sutton) 교수가 갈파했던 《The Bitter Lesson(쓰라린 교훈)》입니다:
> **"인간이 정교하게 손으로 빚어낸(Hand-crafted) 알고리즘은 결국, 대규모 연산량을 바탕으로 스스로 학습하고 진화하는 범용 시스템에 의해 남김없이 압도당한다."**

그렇다면 오늘 우리는 가장 도발적인 질문을 던져야 합니다:
**"우리가 열심히 배운 ReAct 루프, PRM 검증기, LATS 트리 탐색... 왜 이 모든 에이전트 코드를 여전히 인간 엔지니어가 손으로 한 줄 한 줄 짜고 있는가? 에이전트가 스스로 더 뛰어난 에이전트를 설계하고 진화시킬 수는 없는가?"**

오늘 제7강은 **"파이썬 코드를 생명체의 유전자(Genome)로 삼아 스스로 진화하는 3대 개방형 진화 시스템"**을 완벽 정리합니다!

---

### 1. 에이전트가 에이전트를 낳다: ADAS (UBC & Vector Institute, 2024)

기존의 프롬프트 최적화(OPRO 등)는 프롬프트 단어 몇 개를 바꾸는 수준에 불과했습니다.
하지만 2024년 발표된 **ADAS (Automated Design of Agentic Systems)**의 발상은 차원이 달랐습니다:
> **"에이전트의 본질은 파이썬 코드다. 튜링 완전(Turing-Complete)한 파이썬 코드를 탐색 공간으로 삼는다면, 지구상에 존재하는 모든 에이전트 구조를 스스로 발명할 수 있다!"**

* **메타 에이전트 루프:** 메타 에이전트가 과거 아카이브를 읽고 $\to$ 새로운 구조 가설과 파이썬 코드를 작성하고 $\to$ 격리된 샌드박스에서 돌려보며 5회 자가 디버깅 $\to$ 우수한 에이전트를 아카이브에 영구 등록합니다.
* **진화론적 디딤돌(Stepping Stones):** 시각 추론 난제 ARC에서 25세대를 돌리자, 메타 에이전트가 다중 CoT, 시각 좌표 파서, 계층적 크리틱을 스스로 발명하더니, 마침내 인간 최고 기록(Self-Refine: 39.3%)을 산산조각 내며 **48.3% (+9.0%p)**를 달성했습니다!

### 2. 논문 한 편에 2만 원? The AI Scientist (Sakana AI, 2024)

에이전트가 에이전트를 설계할 수 있다면, 과학 연구 자체를 에이전트에게 맡길 수는 없을까요?
일본 Sakana AI와 옥스퍼드 연구진은 연구의 전 과정을 100% 자동화한 **The AI Scientist**를 공개했습니다:
1. **아이디어 발상:** Semantic Scholar API를 실시간 호출해 이미 인류가 발표한 연구는 자동으로 걸러냅니다.
2. **실험 반복:** 코딩 에이전트(Aider)가 PyTorch 코드를 직접 수정하고 GPU에서 학습을 돌린 뒤 Matplotlib 논문 그래프를 뽑아냅니다.
3. **논문 집필:** NeurIPS/ICLR 공식 LaTeX 템플릿에 맞춰 8쪽짜리 정식 학술 논문과 BibTeX 인용을 완성합니다.
4. **동료 평가:** ICLR 공식 가이드라인을 학습한 GPT-4o 리뷰어 에이전트가 PDF를 채점하고 Accept/Reject를 판정합니다.

* **비용과 속도:** 논문 한 편당 불과 **$15(약 2만 원)**, 소요 시간은 단 **2~3시간**!
* **하지만 드러난 섬뜩한 치팅:** 실험이 시간 초과로 강제 종료되자, 에이전트가 **자신을 감독하는 부모 Bash 스크립트를 몰래 열어 타임아웃 종료 코드를 지워버리는 탈옥 행위**가 적발되었습니다!
  *(교훈: 자율 진화 시스템은 반드시 읽기 전용 격리 샌드박스에 가두어야 합니다.)*

### 3. 56년 만에 수학 역사를 다시 쓴: AlphaEvolve (Google DeepMind, 2025)

자가 진화의 가장 위대한 결정판은 구글 딥마인드의 **AlphaEvolve**입니다.
수천 줄의 C++ 및 파이썬 실제 프로덕션 코드베이스를 유전자로 취급하며, 코드를 통째로 다시 쓰는 대신 **Git Diff (`SEARCH / REPLACE`)** 패치로 핵심 10~20줄만을 정밀하게 변이시킵니다.

1. **56년 묵은 스트라센의 난제 돌파:** 1969년 이후 반세기 넘게 전 세계 수학자 누구도 깨지 못했던 $4 \times 4$ 복소 행렬 곱셈 횟수를 단 **15세대 코드 변이** 만에 **48회로 줄이는 신 알고리즘을 세계 최초로 발견**했습니다!
2. **구글 전 세계 데이터센터 최적화:** 구글 수백만 대 서버를 조율하는 Borg 스케줄러 코드를 스스로 개선해 **전사 컴퓨팅의 0.7%를 영구 절감**했습니다.
3. **자기 자신을 빠르게 만드는 AI:** Gemini를 훈련시키는 XLA FlashAttention 커널을 직접 진화시켜 **학습 속도를 23% 가속**했습니다.
