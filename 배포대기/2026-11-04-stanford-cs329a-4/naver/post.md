### 1. 생각과 행동의 결합: ReAct (Yao et al., 2022)

과거 AI 학계는 '혼자 생각만 깊게 하는 추론파(CoT)'와 '무작정 검색부터 누르고 보는 행동파(Act)'로 나뉘어 있었습니다.
- **CoT의 문제점:** 외부 환경과 단절되어 거짓 사실을 한번 떠올리면 걷잡을 수 없이 환각이 눈덩이처럼 불어납니다 (HotpotQA 실패의 56%가 환각).
- **Act의 문제점:** "내가 왜 이 검색을 했는지" 작업 기억(Working Memory)을 유지하지 못해 무한 루프에 빠집니다.

스탠포드와 프린스턴 연구진은 이를 하나로 합친 **ReAct (Reasoning + Acting)**를 고안했습니다:
* **행동 공간의 확장:** $\hat = A \cup L$ (물리적 행동 $A$ + 언어적 생각 $L$)
* **사고(Thought) $\to$ 행동(Action) $\to$ 관찰(Observation)**의 끊임없는 교차!
* **결과:** 지식 검색에서의 사실 날조 환각이 놀랍게도 **0%**로 떨어졌습니다.
* **현업 엔지니어링 꿀팁:** 모델이 실제 도구 응답을 기다리지 않고 가짜 Observation을 지어내는 참사를 막으려면 추론 파라미터에 반드시 `stop=["\nObservation:"]`을 걸어야 합니다!

### 2. 컴파일러 에러를 가중치에 새기다: RLEF (Reinforcement Learning from Execution Feedback)

동결된 모델에게 파이썬 에러 메시지를 프롬프트로 주면서 "이 에러 고쳐봐"라고 하면 잘 고칠까요?
놀랍게도 최신 연구들에 따르면 **"에러 메시지를 보여주는 것보다 차라리 아예 안 보여주고 백지에서 새로 짜게 하는 편이 정답률이 더 높다"**는 충격적인 역설이 존재합니다. 사전 훈련 모델은 에러 메시지의 라인 번호와 코드 논리의 상관관계를 분석하는 법을 배운 적이 없기 때문입니다.

이를 근본적으로 해결한 것이 **RLEF (2024)**입니다:
1. **코드 작성 $\to$ 실행 피드백 $\to$ 수정** 과정을 마르코프 결정 과정(MDP)으로 모델링합니다.
2. **공개 테스트(Public)와 비공개 테스트(Private)의 분리:** 모델이 공개 테스트만 맞추려고 하드코딩 치팅(`if input == test_1: return val_1`)을 하는 것을 원천 차단합니다.
3. **PPO 보상 최적화:** 컴파일러 에러와 테스트 통과 여부를 직접 보상으로 주어 가중치를 업데이트합니다.

**결과는 압도적이었습니다:**
`Llama-3.1-70B-Instruct`에 RLEF를 적용하자 단 3번의 재시도($1@3$)만으로 CodeContests 통과율이 **27.5%에서 40.1%로 폭증**했습니다. 이는 무려 100개의 코드를 병렬 샘플링했던 GPT-4 기반 AlphaCodium(29.0%)을 11.1%p나 압살한 수치입니다!

### 3. AI가 AI를 훈육하다: Constitutional AI (Anthropic, 2022)

그렇다면 컴파일러처럼 명확한 정답이 없는 주관적이거나 안전성 관련된 영역에서는 어떻게 피드백을 줄까요?
수천 명의 사람을 고용해 채점시키는 RLHF는 너무 비싸고 주관적입니다.
앤트로픽의 **Constitutional AI (RLAIF)**는 단 한 장의 **자연어 헌법(원칙)**만으로 모델이 스스로를 교정하도록 만듭니다:
1. **비평-수정 SFT:** 초기 답변을 헌법 원칙에 비추어 스스로 비평하고 다시 작성한 고품질 데이터로 지도학습.
2. **AI 선호도 기반 RLAIF:** AI 평가자가 헌법을 바탕으로 선호 점수를 매겨 보상 모델을 학습시키고 PPO를 수행.

이를 통해 수만 시간의 인간 노동을 자동화하며 진정한 **확장 가능한 감독(Scalable Oversight)**이 완성되었습니다.

### 4. 핵심 요약

1. **ReAct:** 생각과 행동을 융합하여 외부 환경과 상호작용함으로써 사실 환각을 0%로 박멸.
2. **RLEF:** 프롬프트 꼼수가 아닌 강화학습(PPO)으로 컴파일러 디버깅 능력을 가중치에 직접 학습시켜 70B 모델로 GPT-4를 압도.
3. **Constitutional AI:** 자연어 헌법을 통해 인간 병목 없이 AI가 스스로를 비평하고 정렬하는 자율 진화 체계 구축.
4. **격리 샌드박스:** 프로덕션에서는 gVisor 일회성 MicroVM과 엄격한 Egress 방화벽, 중단 시퀀스를 갖춘 방어적 실행 환경이 필수.
