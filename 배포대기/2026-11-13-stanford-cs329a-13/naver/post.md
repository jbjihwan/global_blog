## 2. 생각의 사슬(Chain of Thought): 언어 모델에게 작업 기억을 주다

2022년 이전의 표준 언어 모델에게 복잡한 수학 문제를 주면 모델은 즉시 단 하나의 토큰으로 정답을 맞히려고 시도했습니다.
- 예: *"철수는 사과가 5개 있고 영희에게 2개를 준 뒤 3개를 더 샀다. 철수는 사과가 몇 개인가?"* -> 모델의 출력: *"5"* (오답)

트랜스포머 아키텍처는 매 토큰을 생성할 때마다 고정된 층수(Layer)만큼의 전방 계산(Feed-Forward Computation)만을 수행할 수 있습니다. 즉, **단 한 번의 예측에 투입할 수 있는 부동소수점 연산량(FLOPs)에 엄격한 상한선**이 걸려 있는 것입니다.

### Denny Zhou 박사의 발상: CoT 프롬프팅
Denny Zhou 박사 연구팀은 문제를 해결하기 위한 중간 인지 단계를 자연어 토큰으로 명시적으로 출력하도록 유도했습니다:
```text
Question -> [Step 1: 5 - 2 = 3] -> [Step 2: 3 + 3 = 6] -> Final Answer: 6
```

이 간단한 변화로 **PaLM 540B 모델의 GSM8K 수학 벤치마크 정확도는 17.9%에서 56.9%로 수직 상승**했습니다!

### 충격적인 어블레이션 실험: 왜 자연어여야만 하는가?
연구진은 흥미로운 가설을 검증했습니다: *"언어 모델이 잘 푸는 이유가 단지 중간에 점(...)이나 기호만 찍어서 계산 시간을 벌어주었기 때문은 아닐까?"*
- **Equation-Only (수식만 출력):** 성능이 뚝 떨어짐 (복잡한 문장제 문제를 기호로 번역하는 과정에서 실패)
- **Variable-Only (변수 대입식):** 자연어 CoT 대비 절반 수준
- **Dots-Only (생각하는 척 점만 20개 찍기):** 정확도 향상 전혀 없음 (0% 개선)

결론은 명확했습니다: **자연어(Natural Language)는 인류가 수만 년 동안 복잡한 의미 공간을 압축하고 다단계 추론을 엮어내기 위해 발전시킨 가장 완벽한 인지 프로토콜(Cognitive Protocol)**이며, 언어 모델 역시 자연어 토큰을 생성할 때 비로소 트랜스포머의 주의 집중(Attention) 메커니즘을 온전히 활용할 수 있습니다.

## 3. 자기 일관성(Self-Consistency Decoding): 톨스토이의 원리와 다수결

아무리 뛰어난 CoT 프롬프트를 주더라도, 온도가 0이 아닌 이상 모델은 한두 번의 잘못된 추론 경로로 미끄러져 엉뚱한 오답을 낼 수 있습니다.

이때 Denny Zhou 연구팀이 제안한 기법이 바로 **Self-Consistency (자기 일관성 디코딩)**입니다.

```text
               ┌──> CoT Path 1 ──> 정답: 42 (일치)
               │
[Prompt/Query] ├──> CoT Path 2 ──> 정답: 42 (일치)  ===> [Majority Vote] ===> 최종 정답: 42
(T = 0.7 샘플링) ├──> CoT Path 3 ──> 정답: 17 (오답)       (다수결 4:1 압승)
               │
               ├──> CoT Path 4 ──> 정답: 42 (일치)
               └──> CoT Path 5 ──> 정답: 42 (일치)
```

### 톨스토이 수렴의 원리 (The Tolstoyan Principle)
> *"행복한 가정은 모두 엇비슷하지만, 불행한 가정은 저마다의 이유로 불행하다."* — 레프 톨스토이, 『안나 카레니나』

수학적 추론에서도 똑같은 현상이 발생합니다:
- **정답으로 가는 길:** 정답이 '42'라면, 대수를 쓰든 기하학을 쓰든 산수를 쓰든 모든 올바른 논리 경로는 결국 **단 하나의 정답 '42'로 수렴**합니다.
- **오답으로 가는 길:** 도중에 계산 실수를 하거나 잘못된 가정을 하면, 오답은 '17', '99', '-4', '350' 등 **무한한 오답 공간으로 무작위하게 분산(Diverge)**됩니다.

따라서 모델의 생성 온도를 약간 높여($T=0.7$) 5~10개의 서로 다른 생각의 사슬을 뽑아낸 뒤, **가장 많은 표를 얻은 최빈값 정답(Argmax Mode)을 채택하는 다수결 투표(Sample-and-Marginalize)**를 적용하면 놀라운 결과가 나타납니다:
- 별도의 채점기(Reward Model)나 정답 라벨 없이도 순수하게 **GSM8K 성능이 56.9%에서 74.4%로 수직 상승**합니다!
- 또한 투표에서 정답 후보가 얻은 득표율(예: 10표 중 9표)은 **모델 자신의 확신도(Unsupervised Confidence Score)**와 거의 완벽한 선형 상관관계를 보입니다.

## 4. 창발성(Emergence)과 상전이: 물리적 도약인가, 측정 지표의 착시인가?

물리학자 필립 앤더슨(Philip Anderson)은 1972년 사이언스 논문에서 *"양(Quantity)이 극단적으로 많아지면 질(Quality)적인 변화가 일어난다(More is Different)"*고 선언했습니다.

LLM 연구에서도 똑같은 현상이 관찰되었습니다. 모델의 파라미터와 학습 연산량이 **$10^{23}$ FLOPs 임계점**을 넘어서는 순간, 이전 모델에서는 0%였던 3자리 수 곱셈이나 CoT 추론 능력이 수직으로 솟구치는 **창발적 능력(Emergent Abilities)**이 나타난 것입니다.

```text
성능(%)
100 │                                     ▲ 창발적 도약!
 80 │                                   ┌─┘ (CoT 작동)
 60 │                                  ┌┘
 40 │                                ┌─┘
 20 │                                │
  0 └───┴──────────┴──────────┴──────┴─────────────> 학습 연산량 (FLOPs)
     10^20       10^21      10^22   10^23
```

### 지표의 착시(Metric Mirage) 가설과 반박
스탠퍼드 연구진(Schaeffer et al., 2023)은 다음과 같이 비판했습니다:
- *"창발성은 모델 지능이 갑자기 도약한 것이 아니라, 우리가 채점할 때 쓴 **완전 일치(Exact Match, 0점 아니면 100점)**라는 비선형 계단식 지표 때문에 착시가 일어난 것이다!"*
- 만약 `L`단계의 추론 과정에서 각 단계 성공 확률이 `p`라면, 최종 정답률은 $p^L$이 됩니다. 각 단계 확률 `p`가 선형적으로 부드럽게 증가하더라도, 10단계를 곱한 $p^{10}$은 임계값 이전까지 0에 가깝다가 어느 순간 수직 상승하는 것처럼 보인다는 설명입니다.

하지만 Denny Zhou 박사는 이에 대해 명쾌한 인과적 반박을 내놓았습니다:
> *"다단계 연역 추론(Causal Deduction)에서는 선행 논리가 틀리면 후행 결론은 100% 붕괴합니다. 즉, 중간 단계가 불완전하면 정답이 될 수 없다는 비선형성은 인간이 만든 평가 지표의 왜곡이 아니라 **'논리적 추론'이라는 지적 행위 그 자체에 내재된 근본적인 물리적 현실**입니다."*

실제로 토큰당 교차 엔트로피 손실(Cross-Entropy Loss)을 측정해 보아도, 생각의 사슬을 통한 조건부 확률의 분기점에서는 뚜렷한 상전이(Phase Transition)가 관찰됩니다.

## 5. 결론: 프롬프트 엔지니어링에서 자율 추론 사후 학습(RLVR)으로

오늘날 인공지능 연구는 Denny Zhou 박사의 초기 CoT 프롬프트 발견을 넘어 새로운 국면에 접어들었습니다:
- **인위적 프롬프트의 종말:** 이제 프롬프트에 *"Let's think step by step"*을 적어주지 않아도, **DeepSeek-R1**이나 **o3** 같은 최신 모델들은 사후 강화학습(RLVR / GRPO)을 통해 스스로 `<think>` 태그를 열고 자율적으로 사고의 깊이를 조절합니다.
- **경량 모델로의 증류:** 과거에는 540B 초대형 모델에서만 창발되던 CoT 능력이 데이터 정제와 RL을 통해 **7B, 8B 소형 모델(DeepSeek-R1-Distill-Qwen-7B 등)**에서도 GSM8K 85% 이상을 달성하며 지능의 문턱이 대중화되었습니다.
