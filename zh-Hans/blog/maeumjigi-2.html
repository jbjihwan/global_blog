[Maeumjigi 心语伴侣毕业设计开发日志 #2] 初期提醒 App 规划具象化与测试环境搭建

2026年3月30日 · 阅读需 3 分钟
Jaybee
AI & Robotics Engineer

这是记录 3 月 30 日、正式启动 Maeumjigi 项目雏形“国防会议中心预约提醒”应用程序研发的开发实录。 依托上次确立的团队编码规范，我们制定了详尽的项目推进计划，并为测试驱动开发 (TDD) 筑牢了基底。

规划项目里程碑​

  • 问题背景：应用构想虽已就绪，但亟需明确清晰的分阶段开发实施路径。
  • 推进过程：

    向 Claude Code 提问：“请严格按照 Claude plan.md 推进项目。”

  • 成果沉淀：编制完成了题为 Claude plan.md 的详尽项目规划文档。该文档详细拆解了 Android 客户端、后端服务器架构以及爬虫模块等各阶段的研发目标，成为与 AI 深度协同过程中坚不可摧的技术航标。

构建测试用网页模拟数据（Fixtures）​

  • 问题背景：为了构建能毫秒级捕获预约网站状态变更的高可用爬虫，常规做法需要持续请求线上真实网站。但这不仅会给目标服务器造成额外负载，也使测试环境极不稳定。因此，一个能够在离线状态下自由、安全回归测试的 Mockup 模拟环境不可或缺。
  • 推进过程：

    向 Claude Code 发出指令：“continue”

  • 成果沉淀：AI 自主决策并高质量生成了前后端测试所需的 HTML 静态夹具 (Fixture) 数据。通过精准构建 sample_page.html（全满不可预约状态）与 sample_page_changed.html（退票产生、名额释放状态），为快速、安全地验证服务端爬虫能否准确解析 HTML DOM 树节点变化奠定了极其坚实的技术支撑。

今天，我们真正领略了“AI 驱动型自动化研发”的巨大威力——无需人类逐行给出琐碎指令，仅需一句“按既定规划推进”，AI 即可自主拆解里程碑，并协同构建所需的测试数据集与规范文档。 敬请继续关注这趟波澜壮阔的技术蜕变之旅，见证这款小巧纯粹的提醒 App 如何一步步破茧成蝶，蜕变为前沿深度学习与大语言模型 (LLM) 赋能的重量级毕业设计项目！

核心总结与技术要点​

  • 精细化拆解项目研发里程碑：系统编撰 Claude plan.md 研发蓝图，周密规划 Android 客户端、爬虫服务及通知模块的技术落地步骤。
  • 构建高仿真离线网页测试夹具 (Fixtures)：精准生成满额与退票名额释放两种状态的离线 HTML 样本，杜绝高频请求真实服务带来的风险与抖动。
  • 测试驱动开发 (TDD) 体系奠基：在本地离线环境下实现对 DOM 节点解析与实时状态变更监听算法的极速回归测试。
  • 实证 AI 驱动型自动化研发范式：验证了由宏观规划驱动、AI 自主解耦子任务并自主构建测试夹具与技术文档的高效研发协同模式。
