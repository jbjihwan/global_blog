Este es el registro del 26 de marzo de 2026, el primer día del gran viaje del proyecto final "Maeumjigi".
En aquel momento, en lugar del actual "Maeumjigi" basado en IA, el proyecto dio sus primeros pasos simplemente como una aplicación de alarma para Android.

### El Primer Encuentro con Claude Code

- **Proceso**: El inicio del proyecto fue introducir Claude Code, un asistente de programación de IA, en nuestro flujo de trabajo.
  > "¿Entiendes coreano?"
- **Resultado**: Comenzando con este ligero saludo, empezamos a debatir seriamente sobre la arquitectura del sistema.

### Planificación Inicial de la App de Alarma y Establecimiento de Reglas

- **Problema**: La primera idea que planeamos fue una aplicación práctica para Android que rastreara el estado de reserva de un sitio web específico (MND Convention) y enviara una alarma cuando un horario no disponible cambiara a 'disponible'.
- **Proceso**:
  > A Claude Code: "...Estoy intentando crear una app que envíe una alarma cuando haya una reserva disponible. Por favor, crea un plan paso a paso para hacer esto."
  > "No recibimos alarmas... Construiremos la aplicación Android de acuerdo con Claude.md."
- **Resultado**: Basándonos en el concepto inicial, escribimos `Claude.md` y `CLAUDE_coding_rule.md`, que contenían la dirección de desarrollo del proyecto. En particular, establecimos claramente las convenciones y reglas de programación que el agente de IA debía seguir al escribir código, para evitar cualquier confusión que pudiera ocurrir más tarde al generar cantidades masivas de código automáticamente. Aunque este plan de la aplicación de alarma tomó más tarde un giro masivo hacia un proyecto completamente nuevo basado en IA llamado 'Maeumjigi', establecer la estructura inicial y las reglas de colaboración fue un primer paso crucial. Las plantillas de documentos creadas en este momento también fueron muy útiles más tarde durante el proceso de entrenamiento de modelos a gran escala.

![Captura de Terminal](./images/02_term.png)

Hoy, como el primer día de Capstone Design, sentamos las bases para planificar ideas y comunicarnos con la IA. ¡Por favor, mantente atento a nuestra próxima y espectacular serie para ver cómo este pequeño y simple plan de aplicación para Android evoluciona hacia un ajuste fino masivo de Llama y un proyecto de datos sintéticos de texto a gran escala! El proceso de cambiar el plan inicial es también la belleza de Capstone Design.
