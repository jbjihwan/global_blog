這是記錄 3 月 30 日、正式啟動 Maeumjigi 專案雛形「國防會議中心預約提醒」應用程式研發的開發實錄。
依托上次確立的團隊編程規範，我們制定了詳盡的專案推進計畫，並為測試驅動開發 (TDD) 築牢了基底。

{/* truncate */}

### 規劃專案里程碑

- **問題背景**：應用構想雖已就緒，但亟需明確清晰的分階段開發實施路徑。
- **推進過程**： 
  > 向 Claude Code 提問：「請嚴格按照 Claude plan.md 推進專案。」
- **成果沉澱**：編制完成了題為 `Claude plan.md` 的詳盡專案規劃文件。該文件詳細拆解了 Android 客戶端、後端伺服器架構以及網路爬蟲模組等各階段的研發目標，成為與 AI 深度協同過程中堅不可摧的技術航標。

### 建置測試用網頁模擬資料（Fixtures）

- **問題背景**：為了建置能毫秒級捕獲預約網站狀態變更的高可用爬蟲，常規做法需要持續請求線上真實網站。但這不僅會給目標伺服器造成額外負載，也使測試環境極不穩定。因此，一個能夠在離線狀態下自由、安全回歸測試的 Mockup 模擬環境不可或缺。
- **推進過程**：
  > 向 Claude Code 發出指令：「continue」
- **成果沉澱**：AI 自主決策並高質量產生了前後端測試所需的 HTML 靜態夾具 (Fixture) 資料。透過精準建置 `sample_page.html`（全滿不可預約狀態）與 `sample_page_changed.html`（退票產生、名額釋出狀態），為快速、安全地驗證伺服器端爬蟲能否準確解析 HTML DOM 樹節點變化奠定了極其堅實的技術支撐。

![終端機控制台截圖](./images/02_term.png)

今天，我們真正領略了「AI 驅動型自動化研發」的巨大威力——無需人類逐行給出瑣碎指令，僅需一句「按既定規劃推進」，AI 即可自主拆解里程碑，並協同建置所需的測試資料集與規範文件。
敬請繼續關注這趟波瀾壯闊的技術蛻變之旅，見證這款小巧純粹的提醒 App 如何一步步破繭成蝶，蛻變為前沿深度學習與大型語言模型 (LLM) 賦能的重量級畢業專題專案！

## 核心總結與技術要點

- **精細化拆解專案研發里程碑**：系統編撰 `Claude plan.md` 研發藍圖，周密規劃 Android 客戶端、爬蟲服務及通知模組的技術落地步驟。
- **建構高仿真離線網頁測試夾具 (Fixtures)**：精準產生滿額與退票名額釋出兩種狀態的離線 HTML 樣本，杜絕高頻請求真實服務帶來的風險與抖動。
- **測試驅動開發 (TDD) 體系奠基**：在本地離線環境下實作對 DOM 節點解析與即時狀態變更監聽演算法的極速迴歸測試。
- **實證 AI 驅動型自動化研發範式**：驗證了由巨觀規劃驅動、AI 自主解耦子任務並自主建構測試夾具與技術文件的高效研發協同模式。
