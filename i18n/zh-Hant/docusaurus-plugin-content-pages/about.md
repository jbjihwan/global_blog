# 關於作者 (About) 與 Global Dev Blog

歡迎來到 **Global Dev Blog**，這是由 AI 與機器人軟體工程師 **Jihwan Park (jbjihwan)** 撰寫的獨立工程實驗筆記與技術出版物。

本部落格記錄了在**人工智慧系統、機器人技術、深度計算機視覺、自主審計與雲端安全**領域中的一手工程研究、真實部署挑戰、架構權衡與實證基準測試。

---

## 👨‍💻 作者簡介

- **自主系統與強化學習 (Reinforcement Learning)**：MDP 構建、648 個連續狀態空間離散化、密集速度/距離獎勵塑形，以及從 Webots 物理模擬到 Arduino 微控制器的 Sim-to-Real 硬體遷移。
- **深度計算機視覺 (Deep Computer Vision)**：30 FPS 即時多階段推理管線、目標檢測 (YOLOv3/v5/v8)、光學追蹤 (CSRT)、深度超分辨率 (EDSR) 與基於時序多數決投票的車牌識別 (ANPR) 引擎。
- **高風險 NLP 與 AI 安全性 (Safety AI)**：極端類別不平衡 (524:1) 下的序數回歸 (Ordinal Regression)、弱標籤校準、單調性概率保證與亞毫秒級確定性 Safety Wrapper 護欄架構。
- **公共財政 AI 審計 (Autonomous Budget Audit)**：0.00% 財務計算幻覺的 Text-to-SQL 推理、3D 目標矩陣分割 (消除 85% 噪音) 與 GraphRAG 實質受益人追蹤。
- **全端 ML 基礎設施與供應鏈安全**：高吞吐量 FastAPI 微服務、`npm overrides` 與 `--omit=dev` 遞移依賴安全性強化。

## 🛡️ 內容審查與編輯政策 (Editorial Policy)

為確保最高水準的工程誠信，**Global Dev Blog 恪守嚴格的技術寫作準則**：

1. **100% 實證測試與可重現性**：  
   本站發布的所有架構模式、SQL 查詢、機器學習管線與修復方案，均在真實硬體實驗室 (NVIDIA RTX 4060 GPU, Ubuntu Linux / WSL2, Python 3.12, TypeScript, Webots) 實際執行並通過驗證。
2. **零幻覺保證 (Zero Hallucination)**：  
   絕不複製未經驗證的理論代碼或通用 AI 摘要。所有故障特徵、基準數據與異常追蹤均直接取自測試套件與 CI/CD 日誌。
3. **失敗案例與架構權衡公開**：  
   我們深信記錄緩衝區死鎖、循環依賴崩潰與貝葉斯先驗偏倚等真實挫折，對工程同行而言遠比粉飾的成功更有價值。
4. **開源責任與透明度**：  
   所有文章均關聯至可驗證的 GitHub 代碼庫 ([github.com/jbjihwan](https://github.com/jbjihwan))，歡迎同行查閱與檢驗。
