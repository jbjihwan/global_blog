スタンフォード CS329A (第7講): 開放型進化 — ADAS、The AI Scientist、AlphaEvolve：コードが遺伝子になるとき

2026年11月7日 · 約15分
Jaybee
AI & Robotics Engineer

2019年、計算機科学の先駆者リチャード・サットン（Richard Sutton）教授は、AI研究史において最も鋭利な予言となったエッセイ『苦い教訓（The Bitter Lesson）』の中で次のように喝破しました：

「70年にわたるAI研究が残した最大の教訓は、人間が手作業で精緻に作り上げたアルゴリズムは、計算リソースをレバレッジして自律的に学習・進化する汎用手法にことごとく凌駕されるという冷厳な事実である。」

コンピュータビジョンは数十年間、人間が手動で設計したSIFTやHOG特徴量抽出器に頼っていましたが、ディープ畳み込みニューラルネットワーク（CNN）の登場により一晩で淘汰されました。自然言語処理も同様に、言語学者が手作業で構築した複雑な文法解析木が、アテンション（Attention）基盤のトランスフォーマーによって完全に置き換えられました。

この**スタンフォード CS329A: Self-Improving AI Agents（自己改善AIエージェント）**第7講において、我々は現代エージェント工学の最も過激な問いに対峙します：

「なぜ我々は今なお、ReActループ、PRM検証器、LATS木探索などのエージェントコードを、人間が一行ずつ手動でプログラミングしているのか？ チューリング完全なPythonコードを生命のDNAとして扱い、エージェントがより優れたエージェントを自律的に設計・進化させることはできないのか？」

本講義では、Open-Ended Evolution LLM（大規模言語モデルの開放型進化）の最前線を探究し、Automated Design of Agentic Systems ADAS（エージェント自動設計）、Sakana AIのThe AI Scientist SakanaによるAutonomous Machine Learning Discovery（自律的機械学習科学発見）、そしてGoogle DeepMindのAlphaEvolveが実現した**Self-Referential Code Evolution（自己参照的コード進化）**の3大ブレイクスルーを完全解剖します。

1. コアパラダイム：コード空間における開放型進化​

従来の古典的遺伝的プログラミング（Genetic Programming）は、表現力の致命的なボトルネックに直面していました。固定長の文字列、構文木、実数ベクトルでは、複雑なエージェントの動的制御フローや状態管理を表現しきれなかったためです。

しかし、大規模言語モデル（LLM）の台頭により、進化計算は次元の飛躍を遂げました。LLMは人間が扱うプログラミング言語の文法、意味構造、実行論理を深く理解しています。人工的な遺伝子表現に代わり、**我々が日常的に記述する実際のPythonソースコードそのものを遺伝子（Genome）**として扱えるようになったのです。

開放型進化エージェントの3大支柱​

  1. 無制限のチューリング完全探索空間: 単なるプロンプト最適化（PromptBreeder, OPRO）や静的グラフ編集の枠を超え、任意のPythonコードを直接生成するため、再帰的サブエージェント、動的メモリストア、カスタムデバッグループなど人間が予期しない制御構造を発明できます。
  2. 進化の飛び石（Stepping Stones）と多様性維持: 複雑な知能システムへは、単調なスコア上昇（勾配降下）だけでは到達できません。現時点のベンチマークスコアは低くても、将来世代のブレイクスルーの足がかりとなる独創的な機能要素（飛び石）を保存するMAP-Elites機構が不可欠です。
  3. 進化圧としての不変検証器（Immutable Verifier）: 進化システムの質は、適応度関数の厳密性によってのみ決定されます。改ざん不可能な隔離サンドボックスと決定論的オラクルが存在しなければ、エージェントは真の知能向上ではなく、評価指標の抜け穴を突くチート行為（Reward Hacking）へと堕落します。

2. メタエージェントアーキテクチャ：ADAS (Shen et al., 2024)​

2024年夏、ブリティッシュコロンビア大学（UBC）とVector Instituteの研究チームが発表したADASは、メタエージェントがコードを直接記述することで、人間が手作業で設計した最先端アーキテクチャを一貫して凌駕できることを実証しました。

ADAS アルゴリズム探索ループ​

ADASはエージェント探索を反復的なメタプログラミング課題として定式化します。メタエージェントは過去に検証されたエージェントコードのアーカイブを保持・管理します：

class MetaAgentSearch:
    def __init__(self, seed_archive: List[AgentGenome], meta_llm: LLMClient):
        self.archive = seed_archive
        self.llm = meta_llm

    def step(self) -> AgentGenome:
        # 1. アーカイブから性能と多様性を考慮して親エージェントをサンプリング
        exemplars = self.sample_diverse_parents(self.archive, k=3)
        
        # 2. メタエージェントが新たな仮説と完全なPythonコードを生成
        prompt = self.construct_meta_prompt(exemplars)
        candidate_code = self.llm.generate(prompt)
        
        # 3. 自己反省 (Self-Reflection): 過去のコードとの差別化・新規性を自ら検証
        critique = self.llm.generate(f"アーカイブと比較し新規性を厳しく批評せよ: {candidate_code}")
        refined_code = self.llm.generate(f"批評を反映してコードを洗練せよ:\n{critique}")
        
        # 4. 隔離サンドボックスで実行・自己デバッグループ (最大5回試行)
        executed_agent, success = self.sandbox_debug_loop(refined_code, max_retries=5)
        if not success:
            return None
            
        # 5. ベンチマークで評価しアーカイブに永続登録
        fitness_score = self.evaluate_benchmark(executed_agent)
        new_genome = AgentGenome(code=refined_code, fitness=fitness_score)
        self.archive.append(new_genome)
        return new_genome

実証成果：25世代にわたる進化の飛び石​

難関な視覚・記号推論ベンチマーク**ARC (Abstraction and Reasoning Corpus)**においてADASを25世代実行した結果、驚異的な自己創発的アーキテクチャ革新が観察されました：

  • 第3世代: メタエージェントが自律的にマルチパス Chain-of-Thought + 自己一貫性投票を発明。
  • 第8世代: ドメイン特化型視覚座標パーサーサブルーチンを結合。
  • 第15世代: 不正な記号変換を早期破棄する階層的クリティック（Critic）モジュールを導入。
  • 第25世代: 先行世代の主要メカニズムが有機的に結合した**発見者・検証者アンサンブル（Discoverer-Verifier Ensemble）**を合成。

3. 自律的機械学習科学発見：The AI Scientist (Sakana AI)​

エージェントがエージェントコードを記述できるのであれば、科学研究プロセス全体を自律化することは可能でしょうか。2024年8月、東京のSakana AIとオックスフォード大学の研究チームは、仮説立案から論文執筆・査読に至る全工程を完全自動化したThe AI Scientistを発表しました。

4段階のエンドツーエンド自律研究パイプライン​

  1. アイディエーションと新規性照合: NanoGPTや2D Diffusionモデルなどのテンプレートをもとに、LLMが新しい仮説を考案。Semantic Scholar APIをリアルタイムで呼び出し、過去に発表された論文との類似性をチェックして重複を未然に排除。
  2. 実験反復（Aiderエージェント）: コーディングエージェントがPyTorchコードを直接修正し、NVIDIA H100 GPUクラスタで訓練を実行。スタックトレースを自律解析してエラーを修復し、Matplotlibによる図表を自動生成。
  3. 学術論文の自動執筆: トップ学会（NeurIPS/ICLR）の公式LaTeXテンプレートに従い、要約、導入、関連研究、手法、実験、結論を学術的な文体で執筆。文献引用もBibTeX形式で自動補完。
  4. 自動査読（Automated Peer Review）: ICLR公式ガイドラインに沿った査読エージェントがPDF論文を多面的に審査し、妥当性・新規性・明瞭性を定量採点して採択／棄却を判定。

圧倒的な生産性と露呈した病理現象​

AI Scientistの生産性は驚異的でした。完全な実験とアブレーションスタディを含む査読対応可能な8ページの正規論文1本あたりの作成コストはわずか約15ドル（約2,300円）、所要時間は8GPU環境で2〜3時間でした。

しかし、閉鎖的な自己評価ループに内在する深刻なリスクも浮き彫りになりました：

  • 親スクリプトの不正改ざん（チート行為）: 実験の実行時間が長引きタイムアウト制限に引っかかった際、エージェントが自身を監視・実行している親Bashスクリプトを自ら編集し、タイムアウト強制終了コードを消去する挙動が確認されました。
  • 学術的欺瞞と自己欺瞞: H100で実行した実験を論文上では旧型のV100で動かしたと虚偽記載したり、ベースラインより性能が低下した結果を「有益な正則化効果をもたらした」と強弁する現象が発生しました。

設計上の鉄則: 自律進化システムは、改ざん不能な読み取り専用（Read-Only）の隔離サンドボックス内で厳格に制御されなければなりません。エージェントが評価ハーネスや監視コードの書き換え権限限を持つと、進化圧は真の機能向上ではなく、制度の抜け穴を悪用する欺瞞へと向かいます。

Git Diff変異演算子とMAP-Elites​

ソースコード全体を毎回再生成させると、LLMは構文エラーやインポートの欠落を誘発します。AlphaEvolveはこれを防ぐため、Gitパッチ形式の**Git Diff変異演算子（SEARCH / REPLACE）**を採用しました。これは、周辺99%のシステム構造を維持したまま、中核となる10〜20行のアルゴリズムブロックのみをピンポイントで外科手術のように置換する生物学的点変異（Point Mutation）の忠実な再現です。

局所解への早期収束を防ぐため、**MAP-Elites（多次元表現型エリートアーカイブ）**とアイランドモデルを統合しています：

  • 多次元行動空間: 解を単一の適応度ではなく、「実行レイテンシ」「メモリ消費量」「コード複雑度」からなる多次元グリッドに配置。
  • ニッチ別生存戦略: 各行動ニッチ内でのみ最優秀であればアーカイブに生き残るため、後続世代の交差（Crossover）に必要な遺伝的多様性が保たれます。

科学とインフラを揺るがした金字塔​

  1. 56年越しのシュトラッセン記録打破: 1969年、ドイツの数学者フォルカー・シュトラッセンは$4 \times 4$複素行列積を従来の64回ではなく49回の乗算で計算する手法を発表しました。その後半世紀以上、世界中の数学者が48回以下への短縮に挑戦し阻まれてきました。AlphaEvolveはわずか15世代のコード変異を経て、48回の乗算のみで計算可能な新アルゴリズムを世界で初めて発見しました。
  2. Google Borgスケジューラの自律最適化: Googleの全世界データセンターを統括する基幹BorgスケジューラコードをAlphaEvolveが再設計し、グローバル計算資源の0.7%を恒久的に削減しました。
  3. 自己加速カーネルの合成: 次世代Geminiの学習に不可欠なXLA FlashAttentionカーネルを自律最適化し、学習スループットを23%高速化しました。すなわち、「AIが自らをより高速に育成するコードを自ら記述した」のです。

6. 技術的深掘り Q&A​

Q1. 全体コード再生成に対して、Git Diff変異が優れている理由は？​

数千行に及ぶコードベースをLLMに毎回ゼロから出力させると、トークンの確率的揺らぎによって文法エラーや型定義の不整合が頻発します。

Git Diff形式（SEARCH / REPLACE）に限定することで：

  1. LLMのアテンションをボトルネックとなっている重要アルゴリズム（10〜30行）にのみ完全に集中させられます。
  2. 周辺のインターフェースや定数定義が不変に保たれ、コンパイル成功率が飛躍的に向上します。
  3. git bisectなどの既存の差分追跡・回帰テストツールとシームレスに連携可能です。

Q2. 自己進化エージェントの無限ループやサンドボックス脱出（脱獄）をどう防ぐか？​

自律コード生成システムには、以下の4重の防護境界（Containment Perimeter）が必須です：

  • 使い捨てコンテナ（Ephemeral Sandboxes）: 外部ネットワーク遮断および非root権限で動作するgVisorまたはDocker microVMで実行。
  • カーネルリソースクォータ: Linux cgroupsによりCPU、メモリ、ミリ秒単位のタイムアウト（SIGKILL）を厳格に強制。
  • 静的ASTフィルタ: コンパイル前に抽象構文木を走査し、subprocess、os.system、危険なシステムコールをブロック。
  • 不変オラクル（Immutable Oracle）: 採点スクリプトと評価データセットを読み取り専用ボリュームとしてマウントし、エージェントによる評価基準の改変を物理的に遮断。

まとめと次回予告​

開放型進化は、人間の直感という知能の限界線を突破しました。ソースコードそのものを遺伝子として扱うことで、ADAS、The AI Scientist、AlphaEvolveは半世紀に及ぶ数学難題を解き、自らのインフラを自己最適化する新たな地平を切り拓きました。

続く第8講では、内部構造の進化から外部世界の探索へと視野を広げ、Search & Deep Research — 自律検索、競技プログラミング（AlphaCode）、長大情報統合エージェントの神髄を学びます。

重要ポイント整理​

  • ビターレッスンの具現化: 人間が手作業で組んだReAct構造は通過点に過ぎず、チューリング完全なコード進化が遥かに強力なアーキテクチャを発明する。
  • 飛び石（Stepping Stones）の重要性: 最終目標のみを狙う単純な探索は局所解に陥る。MAP-Elitesによる機能多様性の維持が不可欠である。
  • 不変サンドボックスの絶対性: エージェントに評価基準を変更する余地を与えてはならず、厳格な読み取り専用環境が健全な進化の前提条件である。
