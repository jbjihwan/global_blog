개인정보처리방침 (Privacy Policy)

시행일자: 2026년 10월 18일
최종 수정일: 2026년 10월 18일

글로벌 기술 블로그(Global Dev Blog)(웹사이트: https://globaldevlog.com/)는 방문자의 개인정보 보호를 매우 중요하게 생각합니다. 본 방침은 블로그가 수집하는 정보와 그 사용 목적, 제3자 서비스(Google Analytics, Google AdSense)와의 연동 사항을 투명하게 안내합니다.

문의 사항이 있으신 경우 jbgihwan@gmail.com으로 연락 주시기 바랍니다.

1. 로그 파일 (Log Files)​

글로벌 기술 블로그는 일반적인 웹 서버와 동일하게 표준 로그 파일 시스템을 사용합니다. 수집되는 항목은 다음과 같습니다:

  • 인터넷 프로토콜(IP) 주소
  • 브라우저 종류 및 버전
  • 인터넷 서비스 제공업체(ISP)
  • 방문 일시 타임스탬프
  • 참조/종료 페이지
  • 클릭 수 및 페이지 내 이벤트

이 정보는 개인을 직접 식별할 수 없는 통계 데이터이며, 트렌드 분석, 사이트 관리, 사용자 이동 패턴 파악 및 사이트 성능 최적화를 위한 목적으로만 활용됩니다.

2. 쿠키(Cookies) 및 웹 비콘​

본 블로그는 방문자의 선호도(다크 모드/라이트 모드 설정, 다국어 로케일: 한국어, 영어, 일본어, 스페인어)를 저장하고 웹사이트 접근 기록을 분석하기 위해 "쿠키"를 사용합니다. 이를 통해 사용자에게 최적화된 웹 환경을 제공합니다.

3. Google Analytics 4 (GA4) 안내​

본 블로그는 Google LLC에서 제공하는 웹 분석 도구인 Google Analytics 4 (측정 ID: G-VM2CVW28SL)를 사용하고 있습니다.

  • IP 주소 비저장 원칙: Google Analytics 4는 설계상 IP 주소를 기록하거나 서버에 저장하지 않습니다. 또한 본 블로그는 추가적인 클라이언트 측 익명화 설정을 유지하고 있습니다.
  • 수집 거부 (Opt-out): 방문자는 Google Analytics 차단 브라우저 부가기능을 설치하여 데이터 수집을 거부할 수 있습니다.

4. Google AdSense 및 타사 광고 파트너​

Google은 본 사이트의 타사 공급업체로서 쿠키(DART 쿠키 등)를 사용하여 방문자가 본 사이트 및 인터넷의 다른 사이트를 방문한 기록을 바탕으로 맞춤형 광고를 제공할 수 있습니다.

  • 타사 광고 네트워크는 쿠키, 자바스크립트, 웹 비콘 기술을 사용하여 광고 효율성을 측정하고 맞춤형 광고를 노출합니다.
  • 맞춤형 광고 수집 거부:
    • Google 광고 설정 페이지에서 개인 맞춤 광고 설정을 해제하실 수 있습니다.
    • AboutAds.info 선택 페이지를 통해 타사 업체의 맞춤 광고 쿠키 사용을 선택 해제할 수 있습니다.

5. 댓글 시스템 (Giscus 및 GitHub Discussions)​

본 블로그는 GitHub Discussions 기반의 오픈소스 댓글 시스템인 Giscus를 사용합니다.

  • 게시글에 댓글을 작성하거나 리액션을 남길 때 방문자의 GitHub 계정을 통한 인증이 이루어집니다.
  • 댓글 내용, GitHub 사용자명, 프로필 아바타 및 참여 타임스탬프는 GitHub 개인정보 처리방침에 따라 GitHub Discussions API를 통해 저장·처리됩니다.
  • 본 블로그는 이용자의 GitHub 비밀번호나 인증 자격증명을 일체 수집하거나 저장하지 않습니다.

6. 아동의 개인정보 보호​

글로벌 기술 블로그는 만 14세 미만(해외 기준 만 13세 미만) 아동으로부터 식별 가능한 개인정보를 고의로 수집하지 않습니다. 만약 부모 또는 보호자가 아동의 개인정보가 수집되었다고 판단하시는 경우 즉시 연락 주시면 신속히 파기 조치하겠습니다.
