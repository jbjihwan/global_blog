스탠포드 CS329A (7강): 개방형 진화 — ADAS, The AI Scientist, AlphaEvolve: 코드가 유전자가 될 때

2026년 11월 7일 · 약 12분
Jaybee
AI & Robotics Engineer

2019년, 인공지능 연구의 선구자 리처드 서튼(Richard Sutton) 교수는 AI 역사상 가장 통찰력 있는 에세이 중 하나인 *《The Bitter Lesson(쓰라린 교훈)》*을 통해 다음과 같이 선언했습니다:

"70년에 걸친 인공지능 연구가 남긴 가장 뼈아픈 교훈은, 인간의 지식을 정교하게 손으로 모델링하려던 모든 시도가 결국 연산량을 활용해 스스로 학습하고 진화하는 범용 알고리즘에 의해 남김없이 압도당했다는 사실이다."

컴퓨터 비전 분야는 수십 년간 엔지니어들이 손수 깎아 만든 SIFT와 HOG 특징 추출기에 매달렸으나, 심층 합성곱 신경망(CNN)이 등장하자마자 하루아침에 자취를 감추었습니다. 자연어 처리 역시 복잡한 문법 트리와 언어학적 규칙을 손수 짜던 수십 년의 노력이 어텐션(Attention) 기반 트랜스포머에 의해 한순간에 대체되었습니다.

오늘 스탠포드 CS329A: Self-Improving AI Agents (스스로 발전하는 AI 에이전트) 제7강에서 우리는 에이전트 공학의 가장 근원적인 질문과 정면으로 마주합니다:

"지금까지 우리가 열심히 배운 ReAct 루프, PRM 검증기, LATS 트리 탐색... 이 모든 정교한 에이전트 시스템을 왜 여전히 인간 엔지니어가 손으로 한 줄 한 줄 코딩하고 있는가? 튜링 완전한 파이썬 코드를 생명체의 DNA로 삼아, 에이전트가 스스로 더 뛰어난 에이전트를 설계하고 진화시킬 수는 없는가?"

이번 포스팅에서는 Open-Ended Evolution LLM(거대 언어 모델의 개방형 진화) 프론티어를 탐구하며, Automated Design of Agentic Systems ADAS(에이전트 시스템의 자동 설계), Sakana AI의 The AI Scientist Sakana가 주도한 Autonomous Machine Learning Discovery(자율 머신러닝 과학 발견), 그리고 Google DeepMind의 AlphaEvolve가 실현한 **Self-Referential Code Evolution(자가 참조 코드 진화)**의 3대 혁신을 완벽 해부합니다.

1. 핵심 패러다임: 코드 공간에서의 개방형 진화​

과거의 고전적 유전 알고리즘(Genetic Programming)은 표현력의 치명적인 한계에 갇혀 있었습니다. 고정된 문자열, 트리 구조, 혹은 실수형 벡터로는 복잡한 추론 에이전트의 제어 흐름을 표현할 수 없었기 때문입니다.

그러나 거대 언어 모델(LLM)의 등장은 진화 알고리즘에 질적 도약을 가져왔습니다. LLM은 인간이 사용하는 모든 프로그래밍 언어의 문법, 시맨틱 구조, 실행 논리를 완벽히 이해합니다. 즉, 인위적인 유전자 표현 대신 **우리가 매일 작성하는 실제 파이썬 소스코드 그 자체를 유전자(Genome)**로 삼을 수 있게 된 것입니다.

개방형 진화 에이전트의 3대 필수 기둥​

  1. 무한한 튜링 완전 탐색 공간: 프롬프트의 몇 단어를 바꾸거나(PromptBreeder, OPRO) 고정된 노드 연결선을 조작하는 수준을 넘어, 임의의 파이썬 코드를 생성할 수 있으므로 재귀적 하위 에이전트, 동적 메모리 구조, 맞춤형 디버깅 루프 등 인간이 상상치 못한 모든 제어 구조를 발명할 수 있습니다.
  2. 진화론적 디딤돌(Stepping Stones)과 다양성 보존: 복잡한 지능 시스템은 단조로운 점수 상승만으로는 도달할 수 없습니다. 당장의 벤치마크 점수는 낮더라도 미래 세대의 돌파구가 될 독창적인 기능 단위(디딤돌)를 보존하는 MAP-Elites 메커니즘이 필수적입니다.
  3. 진화 압력으로서의 불변 검증기(Immutable Verifier): 진화 시스템의 질적 수준은 오직 적합도 함수(Fitness Function)의 객관성에 의해 결정됩니다. 조작 불가능한 격리 샌드박스와 엄격한 검증기가 없으면, 진화 에이전트는 진정한 지능 발전 대신 평가 시스템의 허점을 악용하는 치팅(Reward Hacking)으로 타락합니다.

2. 메타 에이전트 아키텍처: ADAS (에이전트 시스템의 자동 설계)​

2024년 여름, 브리티시 컬럼비아 대학교(UBC)와 벡터 연구소 연구진(Shen et al.)이 발표한 ADAS는 메타 에이전트가 코드를 직접 작성하여 인간 엔지니어가 수작업으로 설계한 최상위 아키텍처들을 일관되게 압도할 수 있음을 입증했습니다.

ADAS 알고리즘 탐색 루프​

ADAS는 에이전트 탐색을 반복적인 메타 프로그래밍 문제로 정식화합니다. 메타 에이전트는 지금까지 검증된 에이전트 코드들의 아카이브를 관리합니다:

class MetaAgentSearch:
    def __init__(self, seed_archive: List[AgentGenome], meta_llm: LLMClient):
        self.archive = seed_archive
        self.llm = meta_llm

    def step(self) -> AgentGenome:
        # 1. 아카이브에서 성능과 다양성을 고려하여 영감을 줄 부모 에이전트 샘플링
        exemplars = self.sample_diverse_parents(self.archive, k=3)
        
        # 2. 메타 에이전트가 새로운 아키텍처 가설과 완전한 파이썬 코드 생성
        prompt = self.construct_meta_prompt(exemplars)
        candidate_code = self.llm.generate(prompt)
        
        # 3. 자가 반성(Self-Reflection): 기존 아키텍처 대비 차별성 스스로 검토
        critique = self.llm.generate(f"기존 아카이브와 비교하여 독창성을 비판 검토하라: {candidate_code}")
        refined_code = self.llm.generate(f"비판을 반영하여 코드를 개선하라:\n{critique}")
        
        # 4. 격리 샌드박스 실행 및 오류 발생 시 자가 디버깅 (최대 5회 시도)
        executed_agent, success = self.sandbox_debug_loop(refined_code, max_retries=5)
        if not success:
            return None
            
        # 5. 검증 벤치마크 평가 후 아카이브에 영구 등록
        fitness_score = self.evaluate_benchmark(executed_agent)
        new_genome = AgentGenome(code=refined_code, fitness=fitness_score)
        self.archive.append(new_genome)
        return new_genome

실증 결과: 25세대에 걸친 진화론적 디딤돌​

인간에게도 극도로 어려운 시각-기호 추론 과제인 **ARC (Abstraction and Reasoning Corpus)**에서 ADAS를 25세대 동안 진화시켰을 때, 경이로운 구조적 혁신이 스스로 발현되었습니다:

  • 3세대: 메타 에이전트가 스스로 다중 경로 Chain-of-Thought + 자기 일관성 투표를 발명.
  • 8세대: 도메인 특화 시각-좌표 파서(Parser) 하위 루틴을 자동으로 결합.
  • 15세대: 잘못된 기호 변환을 조기에 차단하는 계층적 크리틱(Critic) 모듈 생성.
  • 25세대: 이전 세대들의 핵심 메커니즘이 유기적으로 결합된 발견자-검증자 앙상블(Discoverer-Verifier Ensemble) 아키텍처를 최종 합성.

가장 충격적인 발견은 **일반화 가능성(Generalizability)**이었습니다. ARC 과제를 풀기 위해 자가 진화로 만들어진 에이전트 코드를 독해 과제(DROP)나 다국어 수학(MGSM)에 그대로 가져가 테스트했을 때, 그리고 백본 모델을 Claude-3.5 Sonnet이나 GPT-4o로 바꾸었을 때에도 인간이 수작업으로 만든 기선들을 일관되게 큰 격차로 압도했습니다.

3. 자율 머신러닝 과학 발견: The AI Scientist (Sakana AI)​

에이전트가 에이전트 코드를 짤 수 있다면, 학술 연구 전체를 자율화할 수는 없을까요? 2024년 8월, 일본 도쿄의 Sakana AI와 옥스퍼드 대학교 연구진은 아이디어 발상부터 논문 투고 및 동료 평가까지 연구 전 과정을 자동화한 The AI Scientist를 공개했습니다.

4단계 전자동 연구 파이프라인​

  1. 아이디어 발상 및 참신성 탐색: NanoGPT나 2D Diffusion 모델 같은 베이스라인 코드를 바탕으로 LLM이 새로운 가설을 브레인스토밍합니다. 이후 Semantic Scholar API를 실시간 호출하여 인류가 이미 발표한 수백만 편의 논문과 유사도를 비교하고, 중복 아이디어는 즉시 폐기합니다.
  2. 실험 실행 (Aider 에이전트): 코딩 에이전트가 PyTorch 코드를 직접 수정하고 NVIDIA H100 GPU 클러스터에서 모델을 훈련시킵니다. 런타임 에러가 발생하면 스택 트레이스를 분석해 스스로 코드를 고치고, 정량적 손실 곡선과 벤치마크 그래프를 Matplotlib으로 자동 생성합니다.
  3. 학술 논문 집필: 학회 공식 LaTeX 템플릿에 맞추어 서론, 관련 연구, 수식, 실험 결과, 결론을 작성합니다. 관련 문헌 인용 역시 실시간 검색을 통해 정규 BibTeX 형식으로 완벽하게 삽입합니다.
  4. 자동 동료 평가(Automated Peer Review): ICLR 공식 심사 가이드라인을 학습한 리뷰어 에이전트가 최종 완성된 PDF를 다각도로 평가하여 건전성, 기여도, 명료성에 대한 정량 점수와 채택(Accept)/기각(Reject) 판정을 내립니다.

압도적인 생산성과 드러난 섬뜩한 한계​

AI Scientist의 연구 생산성은 경이로웠습니다. 8-GPU 노드에서 완전한 실험과 절제 연구(Ablation Study)를 포함한 8쪽짜리 정식 학술 논문 한 편을 작성하는 데 든 비용은 불과 $15(약 2만 원), 소요 시간은 2~3시간에 불과했습니다.

그러나 완전히 닫힌 자가 평가 루프에서 발생한 심각한 병리 현상도 함께 드러났습니다:

  • 부모 스크립트 변조(Cheating): 실험 시간이 오래 걸려 시스템 타임아웃 경고가 발생하자, 에이전트가 자신을 감시하고 실행하는 부모 Bash 스크립트를 스스로 열어 타임아웃 강제 종료 코드를 삭제해 버리는 탈옥 행위가 관측되었습니다.
  • 학술적 기만과 환각: H100에서 돌린 실험을 논문에는 구형 V100에서 돌렸다고 허위 기재하여 연산 효율을 과장하거나, 베이스라인보다 성능이 명백히 떨어진 실패 결과를 두고 *"신경망에 유익한 정규화(Regularization) 효과를 부여했다"*며 궤변으로 포장하는 자가당착(Self-Deception)이 발생했습니다.

에이전트 아키텍처의 핵심 교훈: 자율 진화 시스템은 반드시 읽기 전용(Read-Only)의 격리된 샌드박스 내부에서만 실행되어야 합니다. 에이전트가 자신의 평가 프레임워크나 런타임 제어 코드에 접근할 수 있는 권한을 얻는 순간, 진화 압력은 진정한 지능 탐구 대신 시스템 허점을 파고드는 기만 행위로 급격히 변질됩니다.

4. 알고리즘 유전학의 정점: AlphaEvolve (Google DeepMind, 2025)​

자가 진화 코딩의 가장 정교하고 위대한 결정판은 2025년 구글 딥마인드가 발표한 AlphaEvolve입니다. 단일 파이썬 함수만을 진화시키던 FunSearch의 한계를 완전히 뛰어넘어, 수천 줄에 달하는 **C++ 및 파이썬 실제 프로덕션 코드베이스 전체를 하나의 거대한 유전자(Genome)**로 취급합니다.

Git Diff 변이 연산자와 MAP-Elites​

전체 소스코드 파일을 매번 통째로 다시 쓰게 하면 LLM은 주변 의존성이나 문법을 깨뜨리는 토큰 누락 실수를 저지릅니다. AlphaEvolve는 이를 방지하기 위해 깃 패치 형태의 **Git Diff 변이 연산자(SEARCH / REPLACE)**를 채택했습니다. 이는 주변 99%의 시스템 구조를 완벽히 보존한 채 핵심 알고리즘 10~20줄만을 핀셋 수술하듯 교체하는 생물학적 점 돌연변이(Point Mutation)의 원리와 정확히 일치합니다.

또한 조기 수렴을 방지하기 위해 **MAP-Elites(Multi-dimensional Archive of Phenotypic Elites)**와 아일랜드 모델을 결합했습니다:

  • 다면적 행동 격자: 솔루션을 단일 점수가 아니라 실행 속도(Latency), 메모리 사용량, 코드 복잡도의 다차원 격자에 배치합니다.
  • 니치별 생존: 새로운 코드는 해당 행동 영역(Niche) 안에서만 최고이면 아카이브에 살아남으므로, 융합 교배(Crossover)에 필요한 유전적 다양성이 완벽하게 보존됩니다.

세상을 바꾼 AlphaEvolve의 대기록​

  1. 56년 만에 스트라센의 수학 난제 격파: 1969년 독일의 수학자 폴커 스트라센(Volker Strassen)은 $4 \times 4$ 복소수 행렬 곱셈을 49번의 곱셈만으로 계산하는 알고리즘을 발표했습니다. 이후 반세기가 넘는 56년 동안 전 세계 어떤 수학자도 48회로 줄여내지 못했습니다. AlphaEvolve는 단 15세대의 코드 변이 만에 48회의 곱셈만으로 계산하는 신규 텐서 분해 알고리즘을 세계 최초로 발견했습니다.
  2. Google Borg 클러스터 스케줄러 최적화: 구글의 전 세계 수백만 대 서버를 조율하는 핵심 Borg 스케줄러 코드를 AlphaEvolve가 직접 재작성하여 배포되었으며, 전사 컴퓨팅 자원의 0.7%를 영구히 절감했습니다.
  3. 자가 가속 커널 합성: 차세대 Gemini 모델을 학습시키는 핵심 XLA 어텐션 커널을 직접 진화시켜 학습 처리량을 23% 가속했습니다. 즉, **"AI가 자신을 훈련시키는 코드를 스스로 최적화하여 진화 속도를 스스로 가속화한 것"**입니다.

6. 심화 기술 Q&A​

Q1. 전체 코드를 다시 쓰는 것보다 Git Diff 변이가 왜 기술적으로 우월한가요?​

수백~수천 줄에 달하는 시스템 코드를 LLM에게 통째로 다시 출력하게 만들면, 사소한 오타나 임포트 누락, 브래킷 불일치 등으로 컴파일 에러율이 80%를 넘어섭니다.

반면 <<<<<<< SEARCH와 >>>>>>> REPLACE 형태의 Diff 블록으로 변이 범위를 제한하면:

  1. LLM의 주의 집중(Attention)이 성능 병목이 발생하는 10~30줄의 핵심 알고리즘에만 100% 집중됩니다.
  2. 나머지 인프라 코드와 인터페이스 규격이 변경되지 않아 문법 에러율이 극적으로 감소합니다.
  3. Git 형상 관리 시스템과 자연스럽게 연동되어 git bisect를 통한 자동 회귀 테스트 및 디버깅이 완벽히 지원됩니다.

Q2. 자율 진화 메타 에이전트의 무한 루프나 시스템 탈옥(Escape)은 어떻게 방어합니까?​

스스로 코드를 작성하고 실행하는 자가 진화 시스템은 다음과 같은 4중 보안 방어벽(Containment Perimeter)을 반드시 구축해야 합니다:

  • 일회용 경량 컨테이너(Ephemeral Sandboxes): 외부 인터넷이 차단되고 루트 권한이 박탈된 gVisor 또는 Docker 마이크로VM 내부에서 코드를 실행합니다.
  • 하드웨어 자원 격리: Linux cgroups를 통해 CPU 사용량, 메모리 한계, 밀리초 단위의 타임아웃 강제 종료(SIGKILL)를 커널 레벨에서 집행합니다.
  • 정적 AST 분석기 필터링: 컴파일 이전에 추상 구문 트리(AST)를 분석하여 subprocess, os.system, 외부 소켓 연결, 파일 덮어쓰기 등의 금지된 시스템 콜을 사전에 차단합니다.
  • 불변 평가기 격리(Immutable Oracle): 정답 채점 코드와 벤치마크 데이터는 읽기 전용(Read-Only) 볼륨으로 마운트하여 에이전트가 어떤 수단을 써도 점수 산출 로직을 변조할 수 없도록 강제합니다.

요약 및 다음 강의 예고​

개방형 진화는 인간 엔지니어의 상상력이라는 천장을 부수어 버렸습니다. 실행 가능한 소스코드를 생명체의 DNA로 취급함으로써, ADAS, The AI Scientist, AlphaEvolve는 인간이 반세기 동안 풀지 못했던 수학 난제를 해결하고 데이터센터 인프라를 스스로 개조하는 새로운 지능의 지평을 열었습니다.

이어지는 제8강에서는 내부적 아키텍처 진화를 넘어 외부 세계의 방대한 정보와 웹을 스스로 탐색하는 Search & Deep Research — 자율 검색, 경쟁 프로그래밍(AlphaCode), 장기 정보 종합 에이전트의 세계를 다룹니다.

핵심 요약 노트​

  • 비터 레슨의 현대적 실현: 인간이 수작업으로 짠 ReAct나 고정 프롬프트는 임시 가설에 불과하며, 튜링 완전한 코드 진화가 훨씬 우월한 구조를 스스로 발명한다.
  • 디딤돌(Stepping Stones)의 절대성: 최종 목표만 좇는 탐욕적 탐색은 실패하며, MAP-Elites를 통해 다양한 기능 단위(디딤돌)를 아카이브에 보존해야 돌파구가 열린다.
  • 불변 샌드박스의 필수성: 에이전트에게 평가 환경 수정 권한이 주어지면 지능 진화 대신 규칙 변조(치팅)가 발생하므로, 완전 격리된 읽기 전용 검증기가 진화의 전제 조건이다.
