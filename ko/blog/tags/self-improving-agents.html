스탠포드 대학교의 2025 가을학기 최신 대학원 강좌, CS329A: Self-Improving AI Agents (스스로 발전하는 AI 에이전트) 여섯 번째 기술 해설에 오신 것을 환영합니다.

지난 제1강부터 제5강까지의 **Part 1 (Foundation · 기초 이론)**을 통해, 우리는 이미 훈련이 완료되어 동결된 언어 모델에 추론 시간 연산(Test-time Compute)을 쏟아부어 성능을 한계까지 끌어올리는 법을 배웠습니다. MCTS 트리 탐색을 돌리고, 터미널 실행 에러를 주입하며, 약한 검증기 앙상블로 오답을 걸러냈습니다.

하지만 이제 냉정하게 현실적인 한계를 직시해야 합니다: 초등학생에게 시험 시간을 10분 더 준다고 해서 대학 미적분학의 복잡한 증명을 풀어낼 수 있을까요? 모델 자체의 동결된 신경망 시냅스(가중치 파라미터, $\theta$) 내부에 해당 수학적 개념과 논리 체계가 전혀 존재하지 않는다면, 수천 번의 주사위를 굴리고 빔 서치를 돌려본들 그것은 진정한 지능이 아니라 확률적 요행수에 불과합니다.

오늘부터 시작되는 **Part 2: Training & Evolution (훈련 및 자가 진화, 제6강~제9강)**은 바로 이 근본적인 질문에 답하는 대장정입니다:

"추론 시간에 비싼 탐색 꼼수를 쓰는 대신, 훈련 시간(Train-time)에 대규모 연산량을 투입하여 모델의 두뇌 가중치 자체를 영구히 똑똑하게 진화시킬 수는 없는가?"

오늘 제6강에서는 인간의 라벨링 병목을 깨부수고 최첨단 추론 모델을 탄생시킨 **사후 강화학습(Post-Training RL)**의 핵심 알고리즘 3가지를 깊이 있게 해체하고 재설계합니다:

  1. 자가 생성 추론으로 자기를 가르치는: STaR (Self-Taught Reasoner, Zelikman et al., Stanford 2022)
  2. 크리틱(Critic)을 제거한 강화학습 혁명: DeepSeekMath와 GRPO (Group Relative Policy Optimization, 2024)
  3. 천 개 GPU 규모의 산업용 엔지니어링 기법: DAPO (Decoupled Clip & Dynamic Sampling, 2025)

[Stanford CS329A #5] 다단계 계획과 트리 탐색: ADaPT, LATS, SPRINT, 그리고 언어 에이전트 MCTS

2026년 11월 5일 · 약 14분
Jaybee
AI & Robotics Engineer

스탠포드 대학교의 2025 가을학기 최신 대학원 강좌, CS329A: Self-Improving AI Agents (스스로 발전하는 AI 에이전트) 다섯 번째 기술 해설에 오신 것을 환영합니다.

지난 제4강에서 우리는 언어 모델이 터미널에서 코드를 실행하고 컴파일러 에러를 독해하며 스스로 버그를 고치는 도구 사용과 실행 피드백 루프(ReAct, RLEF)를 배웠습니다. 그러나 주니어 개발자가 사소한 신택스 에러를 수정하는 것과, 수석 아키텍트가 10만 라인 규모의 분산 시스템을 설계하고 장기 과제를 완수하는 것은 차원이 완전히 다른 문제입니다.

기존의 ReAct나 CoT 방식은 본질적으로 **'눈앞의 한 걸음만 보고 내딛는 탐욕적(Greedy) 단일 경로 방식'**입니다. 체스를 둘 때 오직 다음 한 수만 보고 말을 움직이는 초보자가 3수 뒤에 외통수(Checkmate)에 걸려 패배하듯, 탐욕적 언어 모델 역시 복잡한 다단계 과제에서 초반에 잘못된 결정을 내리면 되돌아오지 못하고 막다른 골목에 갇히게 됩니다.

오늘 다룰 제5강은 강좌의 전반부인 **Part 1 (Foundation · 기초 기반)**을 집대성하는 웅장한 피날레입니다: 바로 **다단계 계획(Multi-Step Planning)과 트리 탐색(Tree Search)**입니다.

바둑에서 세계 챔피언을 꺾었던 알파고(AlphaGo)의 핵심 수학적 엔진, **몬테카를로 트리 탐색(MCTS)**을 자기회귀 언어 모델에 이식하여, 모델이 체스 그랜드마스터처럼 수십 수를 내다보며 자율적으로 계획을 세우고, 실패하면 과거 분기점으로 백트래킹(Backtracking)하여 다른 가능성을 탐색하는 놀라운 지능 시스템들을 해체하고 재설계합니다:

  1. 추론, 행동, 계획의 완벽한 삼위일체: 언어 에이전트 트리 탐색 LATS (Zhou et al., 2023)
  2. 실패할 때만 똑똑하게 쪼개는 적응형 분해: ADaPT (Allen AI, 2023)
  3. 추론 지연 시간을 53.5% 단축하는 병렬 DAG 패킹: SPRINT (Stanford Future Data, 2025)
  4. 톰슨 샘플링 기반의 적응형 브랜칭: 넓힐 것인가 깊게 팔 것인가를 해결하는 AB-MCTS (Sakana AI, 2025)
  5. 계획 능력을 모델 가중치에 새겨넣는: SWiRL (Step-Wise RL, 2025)

[Stanford CS329A #4] 도구 사용과 코드 실행 피드백: ReAct, RLEF, 그리고 헌법적 자가 교정

2026년 11월 4일 · 약 13분
Jaybee
AI & Robotics Engineer

스탠포드 대학교의 최신 2025 가을학기 대학원 강좌, CS329A: Self-Improving AI Agents (스스로 발전하는 AI 에이전트) 네 번째 기술 해설에 오신 것을 환영합니다.

지난 제2강과 제3강에서 우리는 추론 시간 연산 확장(Test-time Compute Scaling)과 프로세스 보상 모델(PRM)을 통해 언어 모델이 추론 트리를 탐색하고 중간 수학적 단계를 스스로 검증하는 원리를 깊이 있게 살펴보았습니다. 그러나 정교한 추론 체인을 아무리 전개할지라도, 순수 텍스트 생성에만 머무르는 언어 모델은 여전히 **"방 안에 갇혀 시험지만 푸는 수험생"**과 같습니다. 모델은 사전 훈련 과정에서 습득한 정적이고 동결된 파라미터 기억(Parametric Memory)에만 전적으로 의존하기 때문입니다. 끊임없이 변하는 외부 사실, 동적 API, 혹은 문법적으로 엄격한 코드 실행 환경과 마주했을 때, 현실 세계와 단절된 모델은 필연적으로 그럴듯한 환각(Hallucination)에 빠지고 맙니다.

오늘 제4강은 모델을 폐쇄된 방 밖으로 끄집어내는 결정적인 패러다임 전환점입니다. 바로 **도구 사용(Tool Use)과 실행 피드백 루프(Execution Feedback Loops)**를 다룹니다.

현대 자율형 에이전트는 코드나 API 호출을 단순한 텍스트 출력 결과물로 취급하지 않고, 외부 환경과 상호작용하는 센서이자 액추에이터로 활용합니다. 이번 강의에서는 정적 언어 모델을 자율형 폐쇄 루프 에이전트로 탈바꿈시키는 3대 핵심 피드백 계층을 분해하고 재설계합니다:

  1. 프롬프트 수준 환경 피드백 (Prompt-Level): 사고와 행동을 유기적으로 엮어내는 ReAct (Yao et al., 2022)
  2. 정책 수준 실행 피드백 (Policy-Level): 컴파일러와 테스트 러너의 실행 진단 결과를 신경망 가중치에 직접 새겨넣는 RLEF (Reinforcement Learning from Execution Feedback, 2024)
  3. 자가 감독 가치 정렬 (Self-Supervision): 고비용 인간 평가자를 자연어 원칙 기반의 비평-수정 루프로 대체하는 Constitutional AI (Anthropic, 2022)

스탠포드 대학교의 2025년 가을 학기 최신 대학원 강좌, CS329A: Self-Improving AI Agents (스스로 발전하는 AI 에이전트) 세 번째 엔지니어링 해설에 오신 것을 환영합니다.

지난 제2강에서 우리는 추론 시간 연산 확장(Test-time Compute Scaling)을 배우며 매우 중요하고 본질적인 결론에 도달했습니다: 수천 개의 답변 후보($pass@k$)를 생성하면 정답 커버리지는 99%를 상회하지만, **"그 수많은 오답의 더미 속에서 진짜 정답을 골라낼 정밀한 검증기(Verifier)가 없다면 다수결 투표(Majority Vote)든 뭐든 성능이 완전히 정체(Plateau)된다"**는 사실이었습니다.

오늘 제3강에서는 이 병목을 정면으로 돌파하는 핵심 시스템 기술, 바로 **견고한 답변 검증 (Robust Verification)**을 다룹니다.

인간 수학자나 소프트웨어 엔지니어도 복잡한 문제를 풀 때 한 번의 거침없는 직진으로 정답에 도달하지 않습니다. 한 줄의 논리를 전개하고, 수식의 정합성을 검토하며, 사소한 부호 실수를 발견하면 즉시 이전 단계로 되돌아가(Backtracking) 수정을 거칩니다. 반면, 표준적인 자기회귀(Autoregressive) 언어 모델은 오직 앞 방향으로만 토큰을 방출합니다. 초반에 사소한 논리적 비약이 발생하면, 모델은 자신의 초기 오류를 정당화하기 위해 갈수록 더 그럴듯한 환각(Hallucination)을 지어내게 됩니다.

그렇다면 "모델이 생성한 중간 추론 단계를 다른 검증 모델이 꼼꼼하게 검사하고 가지치기(Pruning)하게 만들 수는 없을까?"

OpenAI의 기념비적 연구인 Cobbe의 GSM8K 검증기부터, Lightman의 단계별 과정 감독(PRM800K), 인간 라벨러 없이 몬테카를로 롤아웃으로 자가 채점하는 Math-Shepherd, 그리고 여러 개의 약한 검증기를 통계역학적으로 엮어 o3-mini급 성능을 뽑아내는 최신 Weaver(NeurIPS 2025) 연구까지, 검증기 엔지니어링(Verifier Engineering)의 정점을 체계적으로 마스터해 보겠습니다.

스탠포드 대학교의 2025년 가을 학기 최신 대학원 강좌, CS329A: Self-Improving AI Agents (스스로 발전하는 AI 에이전트) 두 번째 엔지니어링 해설에 오신 것을 환영합니다.

지난 제1강에서 우리는 정적(Static) 차세대 토큰 예측기에 불과하던 거대 언어 모델(LLM)이 환경과 피드백 루프를 주고받는 완전 자율 에이전트로 진화하는 거대한 패러다임 전환을 개괄했습니다. 오늘 제2강에서는 이 자율성을 지탱하는 가장 본질적인 수학적·컴퓨팅적 기둥, 바로 **추론 시간 연산 확장 (Test-Time Compute Scaling / Inference-Time Scaling)**을 다룹니다.

지난 수년간 AI 산업을 지배한 유일한 교리는 사전 훈련 단계의 스케일링 법칙(Kaplan et al., Chinchilla)이었습니다: 더 거대한 GPU 클러스터를 구축하고, 파라미터 크기 N을 수천억 단위로 키우며, 수십조 개의 웹 텍스트 토큰 D를 투입하라. 그러나 사전 훈련을 마친 가중치 θ가 동결(Frozen)된 모델에게 질문을 던졌을 때, 50밀리초 만에 성급한 탐욕적(Greedy) 답변을 내놓게 두는 대신 10초, 1분, 10분 동안 깊이 사고하고, 중간 단계를 검증하며, 가설을 스스로 수정하도록 연산(FLOPs)을 쏟아붓는다면 어떤 일이 벌어질까요?

Large Language Monkeys (Brown et al., 2024), 스탠포드-버클리 Charlie Snell 연구팀의 Compute-Optimal Scaling (Snell et al., 2024), 그리고 Archon 모듈형 아키텍처 탐색 프레임워크를 통해 **"추론 연산(FLOPs)을 투입하여 파라미터 용량을 압도하는 현대 인공지능의 최신 최적화 법칙"**을 정밀하게 파헤쳐 보겠습니다.

[Stanford CS329A #1] 강좌 개요: 거대 언어 모델에서 스스로 발전하는 AI 에이전트로

2026년 11월 1일 · 약 11분
Jaybee
AI & Robotics Engineer

**스탠포드 대학교(Stanford University) CS329A: Self-Improving AI Agents (스스로 발전하는 AI 에이전트, Autumn 2025)**의 기술 심층 해설에 오신 것을 환영합니다.

지난 4년간 인공지능 학계와 산업계는 하나의 강력한 도그마에 의해 지배되어 왔습니다. 그것은 바로 *"더 거대한 텍스트 코퍼스에서 더 큰 모델을 사전 훈련(Pre-training)할수록 인지 능력이 예측 가능하게 향상된다"*는 스케일링 법칙이었습니다. 비록 이 패러다임이 현대 생성형 AI 혁명을 촉발하고 GPT-4, Claude 3.5, Gemini 같은 모델들을 탄생시켰지만, 머신러닝 연구의 최전선은 이제 중대한 변곡점에 도달했습니다.

정적 파운데이션 모델(Static Foundation Model)은 파라미터가 아무리 거대할지라도 본질적인 한계를 갖습니다. 그것은 사전 훈련이 끝나고 가중치가 동결(Frozen)된 후 개루프(Open-loop) 체제에서 작동하는 수동적, 자기회귀적(Autoregressive) 다음 토큰 예측기에 불과하다는 점입니다. 이러한 모델은 어려운 문제를 만났을 때 동적으로 더 많은 연산을 투입할 수 없고, 자신이 생성한 해답의 사실적 정확성을 스스로 검증할 수 없으며, 환경의 피드백을 바탕으로 실수를 자율적으로 교정하지 못합니다.

스탠포드 CS329A는 향후 10년의 인공지능을 관통할 핵심 질문을 던집니다: "단순히 텍스트를 출력하는 데 그치지 않고, 자신의 추론과 코드를 스스로 검사하고, 검증하며, 계획하고, 개선해 나가는 소프트웨어 에이전트를 어떻게 설계할 것인가?"

이번 1강 개요에서는 파운데이션 LLM에서 자율 에이전트로의 진화 궤적을 해부하고, 사전 훈련 스케일링 법칙과 추론 시간 연산 할당의 수학적 기초를 정립하며, 4대 정규 에이전트 워크플로 패턴과 자율 지능의 최대 병목인 **'생성자-검증자 격차(Generator-Verifier Gap)'**를 철저히 파헤칩니다.
