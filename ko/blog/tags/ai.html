항공작전 동적 임무계획 #1: CPython 탐색 병목 극복과 VRAM 절감 설계

2026년 12월 3일 · 약 15분
Jaybee
AI & Robotics Engineer

💡 핵심 요약 (Executive Summary)

  • 목표한 것: F-16 및 F-15E 항공작전 중 급변하는 전장 상황에 대응하여, 전술 데이터링크(Link 16) 대역폭 내에서 델타(Delta) 임무 계획을 5초 이내에 생성·검증·반영하는 미션 크리티컬 시스템(study_for_sdc) 아키텍처 구축.
  • 마주친 기술적 오류들:
    1. CPython 31.4초 탐색 지연 병목: 100 km × 100 km DEM 격자(10^7 노드)에서 순수 Python heapq와 동적 객체 박싱으로 인해 3D A* 탐색 시간이 31.42초(복잡 지형 최대 48.0초)까지 치솟아 품질 기준 Q_3(<= 5.0 초)를 전면 위반.
    2. 8GB VRAM 환경에서의 2종 LLM 구동 시 CUDA OOM: 7B~8B 매개변수 생성형 LLM 2종을 단일 워크스테이션 GPU에 동시 적재 시 정적 가중치와 KV-Cache, 활성화 메모리 합계가 11.44 GB에 달해 즉각적인 메모리 초과 예외(torch.cuda.OutOfMemoryError) 발생.
    3. 군사 기밀 데이터 부재에 따른 '±1% 연료 계산 정확도' 기준 순환 논증: F-16C의 실제 공력 계수 및 연료 유량 테이블이 군사 2급 비밀로 묶여 있어 실제 기체 대비 오차를 물리적으로 측정할 수 없는 모순 봉착.
  • 엔지니어링 해결 방법:
    1. 오프라인 위협 가시선 사전 베이킹 & 2D 매니폴드 탐색: 런타임 광선 추적(Ray-casting)을 제거하고 시나리오 로딩 시 위협 가시선을 연속 메모리 2D 행렬로 사전 계산(Pre-baking)한 뒤, 수평 2D A* 탐색과 분석적 수직 고도 배정을 결합하여 탐색 지연을 **0.259초(목표치의 1/20 수준)**로 단축.
    2. 생성형 모델 배제 및 고정 차원 비용 가중치 벡터화: KV-Cache가 필수적인 텍스트 생성 모델을 전면 배제하고, 0.28 GB급 인코더(DeBERTa-v3)와 다목적 비용 가중치 벡터 w ∈ [0, 1]^4를 도출하는 초경량 신경망을 채택하여 **총 소요 VRAM을 0.80GB(90% 여유)**로 압축.
    3. BADA 기반 RK4(Runge-Kutta 4th Order) 수치 적분 기준 해석기 구축: 공개된 미 공군 Fact Sheet 제원을 바탕으로 브레게(Breguet) 항속 에너지 방정식을 보정(c_0 = 0.131227 hr^{-1)하여 독립적인 수치해 기준선을 확보, 최대 상대 오차 3.31 × 10^{-5로 Q_2 기준을 수학적으로 통과.

  • 프로덕션 해결책:
    1. SQLite를 WAL(Write-Ahead Logging) 모드로 전환하고 PRAGMA synchronous = NORMAL 및 1,000건 청크 트랜잭션을 적용하여 처리 속도를 초당 95,000건(전체 0.25초)으로 82배 가속.
    2. 형법/특경가법 우선순위 오버라이드 룰과 감액 상한 통제(clamp(cut, 0, budget * 0.70))를 갖춘 PriorityDecisionArbiter 설계.
    3. HTML 엔티티 치환 기반 테이블 정규화기를 도입하여 누적 감사 대장(CUMULATIVE_SURVEILLANCE_AUDIT_LEDGER.md)에 총 23,911건, 121조 7,184억 원의 감액 의결을 단일 결함 없이 완벽 편철.

스탠포드 대학교의 2025 가을학기 최신 대학원 강좌, CS329A: Self-Improving AI Agents (스스로 발전하는 AI 에이전트) 다섯 번째 기술 해설에 오신 것을 환영합니다.

지난 제4강에서 우리는 언어 모델이 터미널에서 코드를 실행하고 컴파일러 에러를 독해하며 스스로 버그를 고치는 도구 사용과 실행 피드백 루프(ReAct, RLEF)를 배웠습니다. 그러나 주니어 개발자가 사소한 신택스 에러를 수정하는 것과, 수석 아키텍트가 10만 라인 규모의 분산 시스템을 설계하고 장기 과제를 완수하는 것은 차원이 완전히 다른 문제입니다.

기존의 ReAct나 CoT 방식은 본질적으로 **'눈앞의 한 걸음만 보고 내딛는 탐욕적(Greedy) 단일 경로 방식'**입니다. 체스를 둘 때 오직 다음 한 수만 보고 말을 움직이는 초보자가 3수 뒤에 외통수(Checkmate)에 걸려 패배하듯, 탐욕적 언어 모델 역시 복잡한 다단계 과제에서 초반에 잘못된 결정을 내리면 되돌아오지 못하고 막다른 골목에 갇히게 됩니다.

오늘 다룰 제5강은 강좌의 전반부인 **Part 1 (Foundation · 기초 기반)**을 집대성하는 웅장한 피날레입니다: 바로 **다단계 계획(Multi-Step Planning)과 트리 탐색(Tree Search)**입니다.

바둑에서 세계 챔피언을 꺾었던 알파고(AlphaGo)의 핵심 수학적 엔진, **몬테카를로 트리 탐색(MCTS)**을 자기회귀 언어 모델에 이식하여, 모델이 체스 그랜드마스터처럼 수십 수를 내다보며 자율적으로 계획을 세우고, 실패하면 과거 분기점으로 백트래킹(Backtracking)하여 다른 가능성을 탐색하는 놀라운 지능 시스템들을 해체하고 재설계합니다:

  1. 추론, 행동, 계획의 완벽한 삼위일체: 언어 에이전트 트리 탐색 LATS (Zhou et al., 2023)
  2. 실패할 때만 똑똑하게 쪼개는 적응형 분해: ADaPT (Allen AI, 2023)
  3. 추론 지연 시간을 53.5% 단축하는 병렬 DAG 패킹: SPRINT (Stanford Future Data, 2025)
  4. 톰슨 샘플링 기반의 적응형 브랜칭: 넓힐 것인가 깊게 팔 것인가를 해결하는 AB-MCTS (Sakana AI, 2025)
  5. 계획 능력을 모델 가중치에 새겨넣는: SWiRL (Step-Wise RL, 2025)

스탠포드 대학교의 최신 2025 가을학기 대학원 강좌, CS329A: Self-Improving AI Agents (스스로 발전하는 AI 에이전트) 네 번째 기술 해설에 오신 것을 환영합니다.

지난 제2강과 제3강에서 우리는 추론 시간 연산 확장(Test-time Compute Scaling)과 프로세스 보상 모델(PRM)을 통해 언어 모델이 추론 트리를 탐색하고 중간 수학적 단계를 스스로 검증하는 원리를 깊이 있게 살펴보았습니다. 그러나 정교한 추론 체인을 아무리 전개할지라도, 순수 텍스트 생성에만 머무르는 언어 모델은 여전히 **"방 안에 갇혀 시험지만 푸는 수험생"**과 같습니다. 모델은 사전 훈련 과정에서 습득한 정적이고 동결된 파라미터 기억(Parametric Memory)에만 전적으로 의존하기 때문입니다. 끊임없이 변하는 외부 사실, 동적 API, 혹은 문법적으로 엄격한 코드 실행 환경과 마주했을 때, 현실 세계와 단절된 모델은 필연적으로 그럴듯한 환각(Hallucination)에 빠지고 맙니다.

오늘 제4강은 모델을 폐쇄된 방 밖으로 끄집어내는 결정적인 패러다임 전환점입니다. 바로 **도구 사용(Tool Use)과 실행 피드백 루프(Execution Feedback Loops)**를 다룹니다.

현대 자율형 에이전트는 코드나 API 호출을 단순한 텍스트 출력 결과물로 취급하지 않고, 외부 환경과 상호작용하는 센서이자 액추에이터로 활용합니다. 이번 강의에서는 정적 언어 모델을 자율형 폐쇄 루프 에이전트로 탈바꿈시키는 3대 핵심 피드백 계층을 분해하고 재설계합니다:

  1. 프롬프트 수준 환경 피드백 (Prompt-Level): 사고와 행동을 유기적으로 엮어내는 ReAct (Yao et al., 2022)
  2. 정책 수준 실행 피드백 (Policy-Level): 컴파일러와 테스트 러너의 실행 진단 결과를 신경망 가중치에 직접 새겨넣는 RLEF (Reinforcement Learning from Execution Feedback, 2024)
  3. 자가 감독 가치 정렬 (Self-Supervision): 고비용 인간 평가자를 자연어 원칙 기반의 비평-수정 루프로 대체하는 Constitutional AI (Anthropic, 2022)
