스탠포드 CS329A (10강): SWE-Agents — 소프트웨어 엔지니어링 에이전트, CodeMonkeys, KernelBench, 그리고 시스템 인터페이스(ASI)

2026년 11월 10일 · 약 10분
Jaybee
AI & Robotics Engineer

현실의 실제 소프트웨어 엔지니어링 현장은 단일 함수를 작성하는 알고리즘 퀴즈나 장난감 벤치마크와는 완전히 다릅니다. 깃허브(GitHub)에 등록되는 수많은 실제 버그 이슈는 단독 파일에 국한되지 않으며, 수백 개의 모듈, 복잡한 레거시 의존성, 그리고 수백만 줄의 대규모 분산 코드베이스 속에 복잡하게 얽혀 있습니다. 더욱이 프로덕션 환경에서 소프트웨어는 단순히 기능적으로 '올바르다(Correct)'는 것을 넘어, '충분히 빠른가(Fast)', 그리고 '물리적 병렬 하드웨어와 완벽히 정렬되어 있는가(Aligned)'라는 냉혹한 다차원 평가를 통과해야 합니다.

오늘부터 시작되는 **스탠포드 CS329A: Self-Improving AI Agents (스스로 발전하는 AI 에이전트)**의 세 번째 거대한 산맥인 **Part 3 · Agent Engineering (L10~L12)**은 연구실의 모델 훈련을 벗어나 프로덕션 소프트웨어 공학의 최전선으로 진입합니다:

"수백만 토큰에 달하는 대규모 엔터프라이즈 레포지토리를 에이전트가 어떻게 탐색하고, 버그를 재현하는 검증 스크립트를 스스로 작성하며, 기존 인간의 PyTorch 베이스라인보다 더 빠른 초고속 GPU 커스텀 커널을 합성해 낼 수 있는가?"

이번 포스팅에서는 SWE-Agent Autonomous Coding(소프트웨어 엔지니어링 에이전트 자율 코딩) 프론티어를 탐구하며, SWE-bench Benchmark GitHub에서 세계 최고 수준의 성과를 거둔 CodeMonkeys Automated Refactoring(코드몽키스 자동 리팩토링), 하드웨어 프로파일러 피드백을 결합한 KernelBench GPU Performance Tuning(커널벤치 GPU 성능 최적화), 그리고 스탠포드 대학교가 제안한 **Agent-Computer Interface ACI(에이전트-컴퓨터 인터페이스 / Agent-System Interface ASI)**의 3대 혁신을 완벽 해부합니다.

스탠포드 CS329A (9강): 사후 훈련의 대진화 — 챗봇에서 자율 에이전트 함대로 (SFT, RLHF, RLVR, Agent RL)

2026년 11월 9일 · 약 10분
Jaybee
AI & Robotics Engineer

인터넷 텍스트의 다음 단어를 예측하는 확률론적 앵무새에 불과했던 원시 언어 모델(Base Model)이 어떻게 인간의 말을 찰떡같이 알아듣는 친절한 비서(Chatbot)가 되었고, 이제 스스로 도구를 쥐고 리눅스 터미널을 조작하며 복잡한 문제를 해결하는 자율 에이전트(Agent)로 거듭나고 있을까요?

오늘 우리는 **스탠포드 CS329A: Self-Improving AI Agents (스스로 발전하는 AI 에이전트)**의 두 번째 거대한 산맥인 **Part 2 · Training & Evolution (L6~L9)**을 완결 짓는 대단원의 자리에 섰습니다. 구글 딥마인드(Google DeepMind)의 선임 연구 과학자 멜빈 존슨(Melvin Johnson)의 시각을 바탕으로, 현대 인공지능이 거쳐 온 사후 훈련(Post-training)의 대진화사를 하나의 웅장한 파노라마로 총정리합니다:

"사후 훈련의 역사는 피드백 신호의 주권을 인간의 손끝(시연 데이터)에서 인간의 눈(선호도 평가)으로, 객관적 검증기(수학/컴파일러)로, 그리고 마침내 물리적 환경 샌드박스의 실행 결과 그 자체로 이양해 온 장엄한 여정이다."

이번 포스팅에서는 **Autonomous Agent Evolution Roadmap(자율 에이전트 진화 로드맵)**을 중심으로, Post-Training LLM Evolution(거대 언어 모델의 사후 훈련 진화), **Supervised Fine-Tuning SFT Agent(지도 미세조정)**의 한계, **RLHF Alignment for Agents(인간 피드백 기반 정렬)**의 성공과 굿하트의 역설, DeepSeek-R1이 촉발한 RLVR(규칙 기반 강화학습), 그리고 **Tool-Grounded Post-Training(도구 기반 사후 훈련)**을 실현한 Agent RL의 최신 지평을 완벽 해부합니다.

스탠포드 CS329A (8강): 검색과 딥 리서치 — 프로그램 공간 탐색(AlphaCode)과 Search-o1의 지식 공간 탐색

2026년 11월 8일 · 약 10분
Jaybee
AI & Robotics Engineer

소프트웨어 엔지니어링이나 최첨단 학술 연구 현장에서 인간 전문가의 진정한 역량은 단 한 번의 암기력으로 증명되지 않습니다. 아무리 뛰어난 전설적인 수석 개발자라도 수천 줄에 달하는 복잡한 분산 동시성 시스템을 첫 번째 타이핑에서 단 하나의 버그도 없이 완성할 수는 없습니다. 노벨상을 수상한 석학이라도 복잡한 유전자 치료제의 분자 구조나 각국의 최신 조세 법안을 검토할 때 머릿속 기억에만 의존해 논문을 쓰지 않습니다.

인간 지능의 진정한 힘은 체계적인 탐색 능력에서 발현됩니다:

"수백만 개의 잠재적 가설을 폭넓게 탐색하고(Search), 불필요한 노이즈를 과감히 가지치기하며(Filter), 추론 도중 발생하는 지식 공백을 외부 데이터베이스에서 실시간으로 보충하여(Retrieve), 분산된 정보들을 엄밀한 통찰로 종합해 내는 역량."

오늘 스탠포드 CS329A: Self-Improving AI Agents (스스로 발전하는 AI 에이전트) 제8강에서는 '검색(Search)'이라는 개념이 어떻게 두 개의 서로 다른 차원에서 인공지능의 성능을 폭발적으로 도약시키는지 살펴봅니다:

  1. 프로그램 공간 탐색 (Program Space Search): 수백만 개의 코드 후보를 생성하고 런타임 행동 시그니처로 압축하는 AlphaCode Competitive Programming(알파코드 경쟁 프로그래밍)
  2. 지식 공간 탐색 (Knowledge Space Search): 장거리 생각의 사슬(Long CoT) 도중 능동적으로 검색을 트리거하는 Search-o1 Autonomous Investigation(자율 탐사) 및 Self-Reflective Search Loops(자가 반성적 검색 루프)
  3. 심층 리서치 에이전트 워크플로 (Deep Research Workflows): 복잡한 질의를 다단계 하위 가설로 분해하고 수백 편의 웹 문서를 정독하여 전문 보고서를 합성하는 **Information Synthesis Agent(정보 종합 에이전트)**의 아키텍처

  • Codeforces

스탠포드 CS329A (7강): 개방형 진화 — ADAS, The AI Scientist, AlphaEvolve: 코드가 유전자가 될 때

2026년 11월 7일 · 약 12분
Jaybee
AI & Robotics Engineer

2019년, 인공지능 연구의 선구자 리처드 서튼(Richard Sutton) 교수는 AI 역사상 가장 통찰력 있는 에세이 중 하나인 *《The Bitter Lesson(쓰라린 교훈)》*을 통해 다음과 같이 선언했습니다:

"70년에 걸친 인공지능 연구가 남긴 가장 뼈아픈 교훈은, 인간의 지식을 정교하게 손으로 모델링하려던 모든 시도가 결국 연산량을 활용해 스스로 학습하고 진화하는 범용 알고리즘에 의해 남김없이 압도당했다는 사실이다."

컴퓨터 비전 분야는 수십 년간 엔지니어들이 손수 깎아 만든 SIFT와 HOG 특징 추출기에 매달렸으나, 심층 합성곱 신경망(CNN)이 등장하자마자 하루아침에 자취를 감추었습니다. 자연어 처리 역시 복잡한 문법 트리와 언어학적 규칙을 손수 짜던 수십 년의 노력이 어텐션(Attention) 기반 트랜스포머에 의해 한순간에 대체되었습니다.

오늘 스탠포드 CS329A: Self-Improving AI Agents (스스로 발전하는 AI 에이전트) 제7강에서 우리는 에이전트 공학의 가장 근원적인 질문과 정면으로 마주합니다:

"지금까지 우리가 열심히 배운 ReAct 루프, PRM 검증기, LATS 트리 탐색... 이 모든 정교한 에이전트 시스템을 왜 여전히 인간 엔지니어가 손으로 한 줄 한 줄 코딩하고 있는가? 튜링 완전한 파이썬 코드를 생명체의 DNA로 삼아, 에이전트가 스스로 더 뛰어난 에이전트를 설계하고 진화시킬 수는 없는가?"

이번 포스팅에서는 Open-Ended Evolution LLM(거대 언어 모델의 개방형 진화) 프론티어를 탐구하며, Automated Design of Agentic Systems ADAS(에이전트 시스템의 자동 설계), Sakana AI의 The AI Scientist Sakana가 주도한 Autonomous Machine Learning Discovery(자율 머신러닝 과학 발견), 그리고 Google DeepMind의 AlphaEvolve가 실현한 **Self-Referential Code Evolution(자가 참조 코드 진화)**의 3대 혁신을 완벽 해부합니다.
